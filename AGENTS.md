# Cloud project workspace

The editable collection of all 27 games is in `YandexGames/project/`.
Read `YandexGames/project/AGENTS.md` and `YandexGames/project/CLOUD.md` before work.
Use that directory for npm commands. Read the selected game's PROJECT.md first.

The older standalone pages in `YandexGames/games/` and other existing website
folders are preserved; do not replace them when editing project sources.

Run browser tests on the Cloud computer, not through the owner's local computer
connection. Never add secrets, tokens, private keys, cookies or local sessions to Git.
