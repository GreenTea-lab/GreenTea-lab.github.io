# Гаражный флиппер / Garage Flipper

3D-симулятор перекупщика машин для Яндекс Игр: покупаете ржавые машины на рынке, торгуетесь с продавцами, моете, выправляете вмятины, срезаете ржавчину, чините механику, красите, тюнингуете и продаёте дороже.

- 11 моделей машин строятся кодом: кузов лофтом из сечений с настоящими вырезами арок, детали кузова с зазорами, фары и решётки наклейками по поверхности, салон, мотор под открывающимся капотом, 6 видов дисков;
- шейдер краски: ржавчина (больше у арок и порогов), вмятины, грунт, выгоревшая краска, грязь, которую стирают пальцем, металлик и перламутр;
- гараж с подъёмником, отражениями (PMREM), тенями, неоновой вывеской, искрами болгарки и пеной;
- рынок объявлений с фото, продавцы и покупатели разных типов, торг в чате, скрытые неисправности, находка дня;
- 7 улучшений гаража, тюнинг (диски, суппорты, спойлер, полосы, посадка), уровни и звания;
- Yandex Games SDK: облачные сохранения, реклама, лидерборд `score` (общая прибыль), покупки `cash_small/medium/large` и `disable_ads`.

## Сборка

```
npm ci
node build.mjs   # dist/ (для консоли) и dist-single/index.html (один файл)
```

## Тесты и промо

```
node tools/balance.mjs           # экономика: прибыль за перепродажу и время до уровней
node tools/music_audit.mjs       # музыка без протяжных и резких нот
node test/carlab.mjs             # контактный лист всех моделей и состояний
node test/ui.mjs [d|m]           # скриншоты экранов в test/out/
node test/flow.mjs               # полный цикл с моком SDK: покупка, ремонт, продажа, реклама, покупки
node promo/art.mjs && sh promo/fit.sh   # иконка, обложки, витрина
node promo/shots.mjs             # скриншоты геймплея
node promo/inapps.mjs            # иконки покупок и CSV
node promo/video.mjs             # видео 16:9 до 8 с, RU и EN
./tools/pack.sh                  # архивы в release/
```

Инструкция по публикации: `release/КАК_ОПУБЛИКОВАТЬ.md`.
