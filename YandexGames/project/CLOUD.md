# Проект в облачной среде

Полный рабочий проект 27 игр хранится в репозитории в `YandexGames/project/`.
Существующие страницы сайта и прежние HTML в `YandexGames/games/` сохраняются;
для разработки используйте исходники в `project/games/`.

## Первый запуск выбранной игры

Из папки `YandexGames/project`:

```sh
npm run list
node tools/cloud-prepare.mjs castaway-solitaire
npm run verify -- --allow-edits
npm start
```

Подготовка устанавливает зависимости только выбранной игры, собирает её и
обновляет её превью. Вместо `castaway-solitaire` можно указать любой ID из
`npm run list`. У HTML-игр отдельная сборка не нужна. Тяжёлые автономные
превью модульных игр не отправляются в Git: они восстанавливаются сборкой.

## Браузерные проверки — только в облаке

В удалённой Linux-среде:

```sh
GAME_TESTS_REMOTE=1 node tools/cloud-prepare.mjs castaway-solitaire --browser
cd games/castaway-solitaire
npm run test:transitions
npm run test:controls
npm run test:release
```

Для другой игры сначала прочитайте её `PROJECT.md` и `package.json`, затем
выберите существующий тестовый сценарий. Не запускайте Chrome или Playwright
на компьютере владельца без его нового явного разрешения. Облачные настройки
должны разрешать загрузку пакетов npm и установку Chrome/Playwright. Ключи и
токены при необходимости задаются в секретах среды, а не в Git.

## Состав публичной копии

Включены исходники всех игр, необходимые статические ресурсы, шрифты,
словарные данные, лицензии, инструкции и тесты. Исключены исходные архивы
`materials/`, сохранённые релизы, ZIP-сборки, логи, результаты тестов,
локальные зависимости и исполняемые файлы. Найденные локальные пути в
публикуемой копии обезличиваются.

Исторические списки импортированных файлов в облачной копии пусты: она не
содержит архивов, поэтому проверка их исходных хешей здесь не выполняется.
Проверка синтаксиса, импортов, локальных ссылок и HTTP-превью сохраняется.
Оригинальные архивы и полная проверка импорта остаются в локальном проекте.

Перед публикацией выполняется поиск встроенных токенов, приватных ключей и
паролей. Не добавляйте `.env`, ключи, cookies, сессии или учётные данные.
