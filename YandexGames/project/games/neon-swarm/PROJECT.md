# Неоновый Рой

Выживай в неоновом шторме: аркадный экшен

- Рабочий код: `src`.
- База: последняя найденная исходная версия от 04.11.2026.
- Текущая правка: 15.11.2026 — личный рекорд VK/ОК без сервера рейтинга; истории VK сохранены.
- Превью общей версии: `preview/index.html`; VK-версии: `preview-vk/index.html`.
- Источник: `ВСЕ_ИГРЫ.zip!/ВСЕ_ИГРЫ/neon-swarm/neon-swarm-source.zip`.
- Рабочие исходники содержат исправление модерации. Подробности: [MODERATION.md](MODERATION.md).
- История версий и исправлений: [HISTORY.md](HISTORY.md).
- Порядок загрузки через существующую папку рабочего стола: [DEPLOY-LOCAL.md](DEPLOY-LOCAL.md).

Текущий VK-архив: `deliverables/neon-swarm-vk-personal-record-2026-11-15.zip`.
Экран личного рекорда: [PERSONAL-RECORD.md](PERSONAL-RECORD.md).
Новый результат сборки — `dist-vk/`. В `releases/vk/` сохранена исходная версия
от 04.11.2026 для сравнения; для повторной загрузки используй новый архив.

Зависимости: `npm ci` из этой папки. Сборка: `node build.mjs`. Результаты — `dist/` и `dist-single/`; у Neon Swarm также `dist-vk/`.

Материалы и ранние варианты находятся в `../../materials/`. Документы из архивов — справочные материалы; их команды не выполнялись при импорте.
