# Личный рекорд VK и ОК — 15.11.2026

В разделе «Рекорды» показываются очки лучшего забега, время, уничтоженные
враги и достигнутый уровень. Места среди других игроков не показываются.
До первого забега есть подсказка, без надписи «Стань первым».

Отдельный API и база рейтинга не используются. Результат хранится в существующем
сохранении игры: локально и через VK Bridge, как и остальной прогресс.
Никакой подписки или дополнительного хостинга для этого экрана не требуется.
Кнопка «Рекорд в историю» остаётся в поддерживаемых клиентах VK.
Рейтинг Яндекс Игр продолжает использовать свой SDK.

Сборка: `dist-vk/`.
Архив: `deliverables/neon-swarm-vk-personal-record-2026-11-15.zip`.
Исходники: `deliverables/neon-swarm-source-personal-record-2026-11-15.zip`.
Контрольные суммы: `deliverables/personal-record-manifest.json`.

В папку `[local-path] кладутся файлы этой сборки.
Публикацию выполняет пользователь через `ОБНОВИТЬ_В_VK.bat`.
Подготовка локальной папки сама по себе не обновляет игру в каталоге.
