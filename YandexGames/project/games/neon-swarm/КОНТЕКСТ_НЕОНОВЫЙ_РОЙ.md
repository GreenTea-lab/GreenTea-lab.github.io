# Неоновый Рой — контекст для продолжения разработки

Передай этот архив в новый чат и напиши, что хочешь изменить. Здесь только исходники Неонового Роя, без сборок, промо и видео.

## Быстрый старт

```
npm install
node build.mjs            # dist/ — для Яндекса (zip содержимого), dist-single/index.html — игра одним файлом
MOCK_LANG=ru node test/flow.mjs          # проверка меню → игра → смерть → меню
SHOP=8 node test/bal30.mjs bot           # бот-прогон 30 минут с прокачанным магазином (SHOP=0 — без магазина)
node test/newfoes.mjs                    # новые враги, боссы и финальная минута
```
Тесты запускать из корня проекта (нужен Chromium для Playwright).

## Карта файлов

- `src/data.js` — оружие (8 видов, по 8 уровней), пассивки, враги и боссы, магазин, кривая опыта `xpNeed`, `WIN_TIME`.
- `src/scenes/GameScene.js` — вся логика боя: спавн, `hpMul`/`dmgMul`, элита, события, боссы, финальная минута `updateFinale`, оружие.
- `src/scenes/HudScene.js` — интерфейс боя, выбор улучшений, предупреждения, победа/смерть.
- `src/scenes/MenuScene.js` — меню: подготовка (герой, арена, сложность), магазин, достижения/эволюции, ежедневное, испытание дня, бой с боссами, настройки. `BgScene.js` — фон (цвет по арене).
- `src/meta.js` — достижения, герои, арены, ежедневная награда и задания, испытание дня (сид по московской дате).
- `src/textures.js` — процедурные текстуры фигур и иконок. `src/audio.js` — звуки (синтез). 
- `src/music.js` + `src/songs.js` — процедурная музыка (8 треков ритмичного неонового электро-попа 100–136 BPM с мелодиями, написанными вручную (поле `mel` в songs.js), мягкий звук: пила только под тёмным фильтром, мягкий малый вместо хлопка, без высоких тарелок, только короткие ноты; пользователь просил «ритмово, но не бить по ушам»).
- `src/i18n.js` — тексты RU/EN. `src/sdk.js` — обёртка Yandex SDK (язык, реклама, лидерборд, облачные сохранения). `src/iap.js` — покупки. `src/save.js` — сохранения.
- `static/` — index.html и шрифты. `test/` — Playwright-тесты, `test/mock/sdk.js` — мок SDK.
- `tools/` — аудит музыки на тянущие звуки (`node tools/music_audit.mjs`) и покадровая запись геймплея (`rec.mjs`).
- `КАК_ОПУБЛИКОВАТЬ.md` — тексты для консоли, теги, ключевые слова, покупки, чек-лист.

## 1. Как мы работаем

- Пользователь (GreenTea) публикует браузерные игры на **Яндекс Играх**. Игры целиком пишет Claude: код, графику (процедурно, без внешних ассетов), музыку и звуки (процедурно, Web Audio), промо-материалы, тексты для консоли и инструкцию по публикации.
- Общение на русском, неформально. Пользователь много тестирует сам и присылает правки пачкой (часто 3–5 пунктов по разным играм в одном сообщении).
- **Важно для пользователя:**
  - После проверки обязательно говорить результат. Был случай: проверку сделали, а итог не написали, и пользователь переспросил.
  - Давать ссылку, чтобы поиграть сразу: игра публикуется как Artifact (одиночный HTML из `dist-single`).
  - Громкость регулируется ползунками (музыка и звуки отдельно), а не просто «вкл/выкл».
  - Нужно много разной музыки, мягкой, «не долбящей». Плейлисты переключаются по настроению: меню, игра, босс, ночь.
  - Графика «милая» и аккуратная. Пользователь замечает странные мелочи: «рот как у клоуна», лозы, торчащие в остров, враги, спавнящиеся далеко за экраном.
  - Сложность не должна превращаться в AFK. Поздняя игра держится на экшене (плотность, события, новые враги), а не только на «толстых» врагах.
- Языки: **русский и английский**. Турецкий не нужен.
- Монетизация: реклама Яндекса (полноэкранная и за награду) плюс инап-покупки: 3 пакета валюты (19/59/149 ян) и «Без рекламы» (99 ян, постоянная покупка).
  - Подключение покупок идёт через ЕЛС в профиле консоли.
  - Подходит ли статус самозанятого — пользователь должен уточнить в консоли или у поддержки Яндекса. Не обещать.
- Каждая игра выдаётся так:
  - `<name>-yandex.zip` — для загрузки в консоль;
  - `<name>-source.zip` — исходники;
  - `promo/` — иконка 512, обложки 800×470 RU/EN, по 4 скриншота desktop 1920×1080 и mobile 1080×1920 на каждый язык;
  - `inapps/` — иконки 256×256 и CSV;
  - `tools/` — аудит музыки на тянущие звуки (`node tools/music_audit.mjs`) и покадровая запись геймплея (`rec.mjs`).
- `КАК_ОПУБЛИКОВАТЬ.md` — шаги, лидерборд, покупки, чек-лист требований, тексты RU/EN для консоли;
  - ссылка на Artifact.

## 2. Неоновый Рой — что уже сделано


- **Тип:** Phaser 3, 2D. Выживание в духе Vampire Survivors.
- **Лидерборд:** `score`.
- **Покупки:** `crystals_500/1800/5000`, `disable_ads`.
- **Арсенал:** 8 видов оружия (blaster, orbit, nova, lightning, missile, laser, saw, drone), одновременно не больше 6; 12 пассивок (в т.ч. multishot +1 снаряд, crit, pierce). Бластер и мультивыстрел выпадают чаще. Магазин постоянных улучшений `m_*` за кристаллы.
- **Музыка Неона** — эпичный синтвейв 108–140 BPM: короткие сав-щипки (`inst: 'saw'`/`'chip'`), аккордовые стабы (`pad` с `stab: 'saw'` и `pat`), панчевый бас (`bass` с `punch: true`), бочка на каждую долю. Попадание ракеты — синтовый звук `mboom` с резонансным фильтром.
- **Враги:** drone, dart, brute, shooter, splitter, а с 6/9/13 минуты lancer (рывок), bomber (взрыв), sniper (веер). Стреляющие: spinner (октагон, крест 4/8 пуль с поворотом, m>5), gunner (кайт, очереди по 3 пули веером, m>8), burster (кольцо 10/16 пуль, m>11). Боссы по кругу `['boss','pulsar','hive']` (флаг `boss:true` в data.js): Звезда, Пульсар (спираль + 6 дронов), Улей (веера + 7 миньонов, ярость <50% HP).
- **Оружие и пассивки:** всё оружие до 8 уровня. `xpNeed`: `5+3.2k+0.42k²` до k=45, дальше линейно +40/ур.
- **Поздняя игра:**
  - цель — 30:00 (`WIN_TIME=1800`);
  - `hpMul`: до 10 мин `1+0.22m+0.035m²`; после — `6.7·1.14^(m−10)` до 20 мин и `·1.19^(m−20)` дальше (≈120 к 29 мин); `dmgMul = 1 + te/650 + max(0,te−1200)/400`;
  - элита: шанс `min(0.3, 0.04+(m−10)·0.013)`, ×4 HP, ×1.4 урона;
  - спавн: `rate` и `maxAlive` растут после 10 мин (лимит ~400);
  - **финальная минута** (`updateFinale`, с 29:00): предупреждение, сразу Пульсар + Улей, спавн ×2.4, HP ×1.5, орбитальные удары каждые 4,5 с;
  - события каждые 16–40 с: орбитальный удар, тараны, элита, камикадзе, снайперы;
  - на 30:00 победа → «Бесконечность» или завершение, открывается «Хардкор» (`te = t*1.08+90`, HP ×1.15, урон ×1.2);
  - после полной прокачки — «Сверхзаряд» (oc_dmg/cd/hp/area).
- **Баланс проверен ботом** (`SHOP=8 node test/bal30.mjs bot`, бот уворачивается идеально): 50 ур. к 10:00, ~92 к 22:00, ~140 к 30:00, элита живёт 7–22 с; в финальную минуту получает урон больше своего макс. HP и выживает впритык. Без магазина (`SHOP=0`) гибнет на 14–16 мин.
- Пилы рисуются полупрозрачными (alpha 0.5, ADD) под врагами, чтобы не закрывать обзор.
- Бластер: 2 снаряда летят параллельно прямо в цель, на 5-м уровне 3 снаряда — средний в цель, боковые веером. Раньше 2 снаряда пролетали мимо мелких врагов.
- Враги спавнятся прямо за краем видимой области (`edgePoint`).

- **Структура:**
  - `src/main.js`;
  - `sdk.js`, `iap.js`, `save.js`, `i18n.js`;
  - `audio.js`, `music.js`, `songs.js`, `volume.js`, `sound-ui.js`, `ui.js`;

### 3.1. Общие модули (dev-kit/shared и template)

**sdk.js** — обёртка над YaGames. Без SDK работает заглушка, так что игра запускается и локально.
- `init()` ждёт `YaGames` до 3 с, затем вызывает `getPlayer({scopes:false})` и подписывается на `game_api_pause/resume`.
- `ready()` вызывает LoadingAPI.ready, когда меню готово.
- `gameplay(on)` вызывает GameplayAPI.start или stop.
- Сохранения:
  - `loadData()`;
  - `saveData(save, flush)` — троттлинг раз в 4 с (лимит 100 вызовов за 5 минут), `flush` сохраняет сразу, после покупок.
- Реклама:
  - `showInterstitial(onDone)` — не показывается, если куплено «Без рекламы»;
  - `showRewarded(onReward, onDone)`;
  - на время рекламы звук и игра на паузе, GameplayAPI останавливается.
- Покупки: `initPayments()`, `product(id)`, `currencyImage()`, `purchase(id)`, `getPurchases()`, `consume(token)`.
- Лидерборд: `submitScore(score)`, `getLeaderboard()`, `login()`. Имя лидерборда задаётся константой `LB_NAME`.

**iap.js** — `iap.init(defs, persist)`, `buy(id)`, `items()`, `available()` и DOM-окно магазина `openStore({title, txt, theme, onBought, onClose})`.
- `defs` имеет вид `{ id: { permanent?, grant(restoring) } }`.
- При старте вызывается `getPurchases`, и выдаётся всё необработанное.
- Расходуемая покупка: `grant`, затем `persist` (setData с flush), затем `consumePurchase`.
- Постоянная покупка (`disable_ads`): `grant` и `persist`, без consume. Восстанавливается через `getPurchases`, флаг дублируется в сохранении.
- Магазин показывается только если в каталоге есть товары. Цены — число плюс иконка яна из SDK.

**music.js** (class Music) — процедурная музыка. Песни задаются данными: `bpm`, `key` (MIDI), `scale`, `prog` (ступени), `seed`, `loops` и слои:
- `pad`, `bass`, `arp`, `lead`, `bell`, `flute`;
- ударные: kick, snare, rim, clap, hat, ohat, shaker, tom, tambourine.

Мелодии сочиняются из seed. Плейлисты по настроению (`define({menu:[…], game:[…], boss:[…]})`), `setMood()` переключает на следующем такте. Песни Неона — `src/songs.js`.

ВАЖНО: пользователь не хочет никаких тянущихся звуков. Пэды, флейты, синт-лиды с сустейном, медь — не использовать вообще. Все ноты короткие и затухающие (≤0,3 с): щипок, маримба, колокольчик, короткий бас. Пэд в данных песни превращается движком в короткие аккордовые щипки на долях 0 и 8.

Дополнительные ограничения:
- мелодии целиком сдвигаются вниз так, чтобы верх был не выше MIDI 81 (~880 Гц), отдельные ноты дополнительно «складываются» по октавам;
- тянущиеся инструменты (flute, lead, synth, brass) не длиннее 0,5 с, сустейн затухает, фильтры не выше 1–2 кГц; колокольчики — слабый обертон и короткий хвост;
- пэды не выше MIDI 74, пила/квадрат в пэдах под фильтром 750 Гц;
- на выходе музыки highshelf −7 дБ от 2,8 кГц и lowpass 6 кГц;
- проверка: `tools/music_audit.mjs` — без звука перебирает все песни и ищет любые ноты длиннее 0,32 с, сустейн, вибрато, пилу и квадрат; все 8 песен Неона проходят.

**volume.js и sound-ui.js:**
- ползунки музыки и звуков 0..1, хранятся в `settings.musicVol` и `settings.sfxVol` (миграция со старых булевых);
- мастер-громкость: 0.7×music и 0.6×sfx;
- `openVolume({...})` открывает DOM-окно.

**save.js** — localStorage плюс облако. При загрузке берётся версия с большим `ts`. Также есть `write()` и `flush()`.

**i18n.js** — RU для ru/be/kk/uk/uz/ky/tg/hy/az/ka, для остальных EN. Функция `t(key)`. Следить, чтобы в словаре не было дублей ключей.

**Скрипты сборки и публикации:**
- `pack.sh <dir> <name>` создаёт `release/<name>-yandex.zip` и `-source.zip`, копирует в outputs и делает `<name>-release.zip`. Путь `/home/claude/$g` в скрипте захардкожен, поправь под новое окружение.
- `to_artifact.py <dist-single/index.html> <out.html> <bg>` убирает doctype, head и body (каркас добавляет Artifact) и задаёт фон страницы.
- `inapps.mjs` рисует иконки покупок 256×256 и CSV для групповой загрузки в консоль.

## 4. Требования Яндекс Игр (чек-лист, всё уже сделано в 4 играх)

- **1.1, 1.19.**
  - `/sdk.js` подключён;
  - `LoadingAPI.ready()` вызывается, когда меню готово;
  - `GameplayAPI.start/stop` размечают игру, паузы, меню, экран улучшений и рекламу.
- **1.19.4.** События `game_api_pause/resume` ставят на паузу игру и звук.
- **1.3.** Звук выключается при сворачивании вкладки и потере фокуса.
- **1.6.1.8, 1.6.2.7, 1.10.2.** Нет контекстного меню, выделения текста, долгого тапа и скролла страницы.
- **1.9, 1.11, 1.13.3.** Облачные сохранения сразу после действий. В черновике отметить «Игра использует облачные сохранения». Троттлинг 4 с.
- **1.12–1.13.** Покупки:
  - консумируются;
  - необработанные проверяются при старте;
  - валюта и иконка берутся из SDK, цены числом;
  - каталог берётся из консоли.
- **4.1–4.7.** Реклама только через SDK и в логических паузах. Ролик за награду — только по кнопке с понятной подписью и только как бонус. Во время рекламы звук и игра на паузе.
- **2.14.** Язык определяется через SDK.
- **1.21, 1.22.** `index.html` в корне архива, имена файлов латиницей, никаких внешних запросов, всё внутри архива.
- **Тексты в консоли:**
  - короткое описание до 70 символов;
  - «Об игре» и «Как играть» от 100 до 1000;
  - SEO от 50 до 160.
- Иконка и обложка — не голый скриншот (5.6): сцена без интерфейса, на обложке название. Скриншоты на языке описания.
- **Лидерборд:** создать в черновике с точным техническим именем, числовой, по убыванию.
- **Покупки:** «Инап-покупки → Инапы», ID ровно как в коде. Свой Яндекс ID добавить в тестовые логины.
- **Типичный цикл рекламы:**
  - полноэкранная — после забега или уровня (кнопки «ещё раз» / «в меню» / «далее»);
  - за награду — воскрешение, x2 награда, переброс, бонус валюты в магазине.

## 5. Тестирование (headless)

- Playwright с Chromium:
  - путь к браузеру: `/opt/pw-browsers/chromium-1194/chrome-linux/chrome`, в новом окружении может отличаться — проверить `ls /opt/pw-browsers`;
  - аргументы: `--use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader --autoplay-policy=no-user-gesture-required`.
- **`test/shot.mjs`** (шаблон `test-shot.mjs`) поднимает HTTP-сервер для `dist/`.
  - `run({w,h,mobile,dpr,debug,steps,locale,pre})`;
  - `pre` — init-скрипт, `debug` попадает в `window.__NS_DEBUG` (или аналог);
  - `MOCK_SDK=1` подменяет `/sdk.js` на `test/mock/sdk.js` (реклама, покупки, сохранения);
  - `MOCK_LANG=ru` переключает язык мока.
- **Отладочные хуки в игре:**
  - `window.__game`, `window.__ns_save`;
  - debug-флаги `bot` (уворачивающийся бот), `afk`, `afkAfter`, `sub` (N шагов симуляции за кадр — ускорение), `autoPick`/`smartPick` (выбор улучшений), `autoEnd`, `god`.
- **Грабли тестов:**
  - swiftshader очень медленный (3–10 FPS). Считать по игровому времени (`g.t`), а не по реальному; для ускорения использовать `debug.sub`.
  - Окно повышения уровня ставит игру на паузу, и тест-цикл может зависнуть. Включать `autoPick`.
  - `pkill -f <шаблон>` убивает и собственный shell, если шаблон есть в тексте команды. Делать pkill отдельным вызовом с шаблоном вида `[t]est/x`.
  - Долгие прогоны запускать через `nohup … &` и опрашивать лог.
- Каждую визуальную правку проверять скриншотом. Баланс проверять ботом и замерами: например, `test/dps.mjs` меряет урон билда по толпе.

### 5.1. Промо-видео и скриншоты (`tools/rec.mjs`)

- Время в странице виртуальное (подмена Date/performance.now и ручной вызов requestAnimationFrame один раз на кадр), кадры снимаются через CDP `Page.captureScreenshot` → ffmpeg. Так видео плавное при любом медленном рендере (~0,3–0,8 с на кадр в swiftshader).
- Не использовать `page.clock` Playwright для этого — скриншоты с ним идут по 10+ секунд.
- Музыка пишется отдельно в реальном времени (перехват подключений к `ctx.destination` → MediaRecorder), затем loudnorm и склейка.
- Сценарии роликов лежали в `promo-video/*.mjs` (режиссёр по таймлайну). Режим скриншотов: между снимками рендер в маленьком окне; для Phaser с отложенным resize (Башни) этот режим ломает кадр — там `noLow: true`.
- Пользователь решил делать видео сам; скриншоты нужны только с геймплеем (≥70% кадра), меню и магазин не годятся.

## 6. Уроки и решения

- Враги должны появляться сразу за краем экрана, иначе игрок их не видит и начало кажется пустым. В Неоновом Рое в начале сразу идёт стайка из 6 дронов.
- Веер из 2 снарядов промахивается по мелким целям. Центральные снаряды должны лететь в цель.
- Музыку переключать на следующем такте, а не по окончании цикла.
- Постоянную покупку сохранять в сейв (fallback), а не только восстанавливать через `getPurchases`.
- Камера в физической игре: показывать реальную катапульту и следовать за снарядом. Оверлей «от первого лица» выглядел плохо.
- Idle-игра: начинать с пустого острова и пошагового обучения, это понятнее, чем сразу готовый остров.
- Кристаллы за убийства в длинных забегах нужно ограничивать (убывающий вклад), иначе обесцениваются покупки.
- Сохранять версию сейва в ключе (`*_v2`), когда меняется стартовое состояние.
- Поля черновика Яндекса: теги до 20, ключевые слова до 100 символов строчными через запятую, категорий не больше 2, maskable-иконка 512, обложка на витрину 1560×520, горизонтальное видео обязательно (MP4, до 28 с), вертикальное по желанию. Готовые теги и ключевые слова Неона — в `КАК_ОПУБЛИКОВАТЬ.md`.
- Промо-скриншоты рендерить скриптом `promo/shots.mjs` (специальная витринная сцена), обложки — `promo/covers.mjs`.

## Версия 2 (эволюции, герои, арены, режимы)

- **Эволюции** (`EVOLVE` в data.js): оружие 8 ур. + своя пассивка → сундук с босса или элиты-вожака превращает его в эволюцию. Логика в `GameScene.openChest/evolve/updateWeapons`, окно в `HudScene.showChest`. «Ещё сундук» за рекламу — один раз за забег.
- **Герои** (`HEROES`): стартовое оружие + модификаторы; открываются за кристаллы или достижение. **Арены** (`ARENAS`): цвет, колонны-препятствия (детерминированно по клетке `PCELL`), свой порядок боссов.
- **Новые боссы**: `serpent` (змей с сегментами `e_seg`) и `mirror` (лучи с предупреждением + зеркальца).
- **Режимы** (объекты с `teMul/teAdd/hp/dmg/rate/reward/stars/win`): спокойный 15 мин (`MODES.calm`), обычный 30 мин, угроза 1–5 (`threatMode`, открываются по очереди победами, старый «хардкор» = угроза 1), испытание дня 10 мин (`DAILY_MODE` + мутатор, без лидерборда), бой с боссами 10 подряд (`RUSH_MODE`, открывается победой над всеми пятью боссами; сила врагов растёт с числом побеждённых боссов).
- **Мета**: 24 достижения с кристаллами, ежедневная награда с серией (30→90, вторая такая же за рекламу), 3 задания в день, звёзды за каждые 5 минут.
- **Интерфейс**: карточки «было→стало», слоты оружия в бою, обучение из 4 шагов с кнопкой «Пропустить», настройка «меньше вспышек и тряски» (`save.reduceFx`).
- Сохранение: ключ тот же (`neon_swarm_save_v1`), новые поля дополняются значениями по умолчанию; `hardWon` переносится в `threatWon`.
- Тесты v2: `node test/v2_ui.mjs land|port` (все окна меню), `node test/v2_game.mjs land|port` (сундук, эволюция, боссы, колонны, бой с боссами), `SHOP=8 node test/bal2.mjs bot 1900 '{"modeId":"normal"}'` (бот с любым режимом).
