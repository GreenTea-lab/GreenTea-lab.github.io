## 1. Что подготовить заранее
1. **Аккаунт VK** с подтверждённым номером. Игру будет видеть и править только он (создатель), остальных можно добавить администраторами.
2. **Node.js** (версия 16 или новее) на компьютере. Проверка: в терминале `node -v`. Скачать: nodejs.org. ✅ Загрузка идёт через консольную утилиту `vk-miniapps-deploy`, ручной загрузки zip в документации нет.
3. **Картинки** (подробно в разделе 5). Их надо нарисовать самому или заказать, я их не делал, потому что не просили.
4. **Контакт для поддержки** (ссылка на сообщество VK или почта). ✅ Это требование модерации. Решить, где он будет: в карточке игры/сообществе или внутри игры. Если нужен пункт в настройках игры, пришли контакт, я добавлю.
5. **Реквизиты для iOS** (если хочешь показывать игру в приложении на iPhone): название компании или ФИО самозанятого/ИП. Без этого на iOS игра откроется в мобильном браузере. ✅

## 2. Создание игры в кабинете
⚠️ Страницу с точными шагами создания в документации я открыть не смог. По навигации документации игры создаются в разделе «Мои приложения» (vk.ru/apps?act=manage).
1. Войди в VK, открой «Мои приложения» → «Создать». Тип: **Игра** (не мини-приложение).
2. Название: **Неоновый Рой** (3–29 знаков). ✅ Название должно быть уникальным, не копирующим другие игры каталога.
3. После создания открой настройки игры и запиши её **ID** (число, понадобится в разделе 3).
4. Раздел «Панель управления → Администраторы»: добавь тех, кто будет тестировать. ✅ Пока игра не прошла модерацию, запустить её могут только создатель и администраторы.

## 3. Загрузка файлов на хостинг VK
✅ Всё по документации «Хостинг → vk-miniapps-deploy».

1. Создай на компьютере пустую папку, например `neon-vk`. Открой в ней терминал.
2. Создай папку `build` и **распакуй в неё `neon-swarm-vk.zip`**, чтобы получилось `neon-vk/build/index.html`, `build/game.js`, `build/phaser.min.js`, два файла `.woff2`.
3. Создай в `neon-vk` файл `package.json`:
```json
{
  "name": "neon-swarm-vk",
  "version": "1.0.0",
  "private": true,
  "homepage": ".",
  "scripts": {
    "deploy": "vk-miniapps-deploy"
  }
}
```
4. Установи утилиту: `npm install @vkontakte/vk-miniapps-deploy --include=dev`
5. Создай рядом файл `vk-hosting-config.json`, подставь свой ID из шага 2.3:
```json
{
  "static_path": "build",
  "app_id": 123456,
  "endpoints": {
    "mobile": "index.html",
    "web": "index.html",
    "mvk": "index.html"
  }
}
```
(В примере документации для мобильного приложения указан отдельный файл, у нас один `index.html` на все платформы.)
6. Запусти: `npm run deploy`.
7. Первый раз утилита покажет ссылку для получения ключа доступа. Открой её в браузере, разреши доступ, вернись в терминал и нажми `y` или Enter. Ключ запомнится.
8. На вопрос «загрузить архив» нажми `y`. На вопросы `Would you like to update prod urls? / dev urls? / test group url?` лучше отвечать `y`: адрес файлов меняется при каждой загрузке, утилита сама пропишет новый в настройках. Для тестовой группы введи её название или оставь пустым.
9. Лимиты: до 24 загрузок в сутки на игру, архив до 300 МБ, хранится до 10 боевых версий. Мы весим 1,4 МБ.
10. Если ошибка `5: User authorization failed`, удали файл ключа (macOS/Linux: `~/.config/configstore/@vkontakte/vk-miniapps-deploy.json`, Windows: `C:\Users\<имя>\.config\configstore\@vkontakte\vk-miniapps-deploy.json`) и повтори шаги 6–7. Если `15: Access denied`, проверь `app_id`.

## 4. Настройка размещения
✅ Раздел «Размещение» в настройках игры. Без него игра не запустится.
1. Если утилита не прописала адреса сама, вставь выданные ею ссылки в поля **Мобильное приложение**, **Web** и **Мобильная версия сайта**.
2. Состояние: **Включено**. ✅ После создания стоит «Отключено», тогда игру видят только админы. «Включено» открывает игру всем по прямой ссылке, но в каталоге её ещё нет.
3. Режим разработки (по желанию): отдельный адрес, который видят только админы. Удобно проверять новую версию, не трогая боевую. ✅ Приоритет для админа: тестовая группа, потом режим разработки, потом основной адрес.
4. Одноклассники: в «Другие площадки» привяжи OK ID. Нужно только если хочешь и туда. Игра появится в течение 15 минут. ✅ Для OK обязательна модерация.

## 7. Тест до отправки
1. Открой игру по ссылке `https://vk.com/app<ID>` с компьютера и с телефона (в приложении VK). Для телефона можно отправить ссылку в чат «Избранное» и открыть сообщение. ✅
2. Пройди: меню → «ИГРАТЬ» → обучение → бой → смерть → «ЕЩЁ РАЗ». Музыку и звук проверь, сверни приложение: музыка должна замолчать.
3. Нажми «ЕЩЁ СУНДУК» или «x2 КРИСТАЛЛЫ». ✅ До модерации реклама тестовая и деньги не начисляются, но ролик должен показаться, а награда выдаться.
4. Закрой игру и открой снова: кристаллы и прогресс должны остаться.
5. Открой консоль браузера (F12) на компьютере. ✅ Модераторы чаще всего отклоняют из-за ошибок в консоли. Красных ошибок быть не должно.
6. Для тестеров можно создать «Тестовые группы» и дать им отдельный адрес. ✅

## 8. Отправка на модерацию
✅ Раздел «Модерация».
1. Проверь, что состояние «Включено» и все поля оформления заполнены (частая причина отказа: настройки не завершены).
2. Выбери платформы: **Мобильные** (Android, iOS, мобильный сайт) и/или **Web**. Площадки: VK, Одноклассники или обе.
3. В поле «Описание основных сценариев» напиши: «Выживалка в жанре roguelike. Игрок двигает героя пальцем, оружие стреляет автоматически. Режимы: обычный на 30 минут, спокойный на 15, угрозы 1–5, испытание дня, бой с боссами. Отличия: эволюции оружия из сундуков боссов, 5 героев, 3 арены, ежедневные задания и достижения. Реклама только по кнопке игрока или между боями.» Это нужно, чтобы показать отличия от похожих игр каталога.
4. Нажми «Пройти модерацию».
5. Срок: обычно 2–7 рабочих дней, статус придёт уведомлением. ✅
6. **Типичные отказы:** игра не включена, ошибки в консоли, реклама сразу после запуска, нет обучения или выключения звука, нет контакта поддержки, игра слишком похожа на существующую.
7. После отказа исправь и отправь снова через чат модерации. Новая версия загружается тем же `npm run deploy` (до 24 раз в сутки).

## 9. Что в VK-версии устроено иначе
| | Версия для Яндекса | Версия для VK |
|---|---|---|
| SDK | Yandex Games SDK | VK Bridge (`VKWebAppInit` отправляется сразу, в пределах 30 секунд) |
| Сохранения | облако Яндекса + localStorage | хранилище VK (`VKWebAppStorageSet`, куски по 2000 знаков, не чаще раза в 20 с) + localStorage |
| Реклама за награду | `showRewardedVideo` | `VKWebAppShowNativeAds` `reward`; награду даю только если VK подтвердил показ |
| Реклама между экранами | `showFullscreenAdv` | `interstitial`, при выходе из боя |
| Кристаллы и «Без рекламы» за деньги | есть | **нет**: VK принимает оплату только голосами и требует свой сервер для уведомлений об оплате |
| Таблица лидеров | `score` | **нет общей**: VK пишет очки в таблицу только с сервера. В «Рекордах» виден личный рекорд |
| Свернул игру | пауза | `VKWebAppViewHide` и `ViewRestore`: пауза музыки и игры |
| Язык | из SDK | `vk_language` из адреса, по умолчанию русский |

**Если захочешь покупки и лидерборд в VK:** нужен небольшой сервер (приём уведомлений об оплате и вызов `secure.addAppEvent`). Скажи, распишу, что нужно.

## 10. Доход от рекламы
✅ До модерации реклама идёт в тестовом режиме. Чтобы показы засчитывались, нужно зарегистрироваться в кабинете выплат VK и пройти модерацию. Правила VK: награду реальными деньгами за просмотр обещать нельзя, роликов подряд показывать нельзя.

## 11. Обновление игры
1. Пересобрать при необходимости: `node build.mjs`, взять `dist-vk/`.
2. Положить содержимое в `build`, выполнить `npm run deploy`.
3. Изменения в уже опубликованной игре не должны нарушать требования, иначе модератор может снять её с каталога. ✅

## 12. Проблемы
| Симптом | Что делать |
|---|---|
| Белый экран в VK | открой консоль (F12), проверь адрес в «Размещении», проверь, что состояние «Включено» |
| Нет рекламы | до модерации она тестовая и может не показываться, это нормально. Реклама подгружается по таймеру, подожди 30 секунд |
| Прогресс не сохраняется | проверь консоль на ошибки хранилища; сохранение идёт не чаще раза в 20 с и сразу при сворачивании игры; на этом же устройстве прогресс дополнительно лежит в localStorage |
| Деплой не работает | см. раздел 3, пункт 10 |
