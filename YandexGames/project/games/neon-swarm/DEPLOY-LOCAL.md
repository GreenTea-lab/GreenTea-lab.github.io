# Как загрузить подготовленное обновление в VK

Проверено по установленным файлам в `[local-path]
Используется `@vkontakte/vk-miniapps-deploy` версии 1.0.3.

1. Запусти `ОБНОВИТЬ_В_VK.bat` из этой папки. Он переходит в свою папку
   и запускает `node deploy-log.js`.
2. `deploy-log.js` запускает уже установленную утилиту и записывает вывод
   в `deploy_log.txt`.
3. Утилита читает `vk-hosting-config.json`: приложение **54817546**, файлы
   из папки **build**, входной файл для всех платформ — **index.html**.
4. Она заново создаёт `build.zip` из папки `build`. Источником загрузки
   являются именно распакованные файлы, поэтому в `build` уже помещена новая версия.
5. В консоли подтверди загрузку. Чтобы заменить рабочую версию, выбери
   `yes` на `Would you like to update prod urls?`. Для обновления версии
   разработки также выбери `yes` на вопрос про `dev urls`. Вопрос про тестовую
   группу используй только если нужна отдельная тестовая группа.
6. Если VK запросит авторизацию или подтверждение на телефоне, выполни их
   самостоятельно. Успешное завершение проверяй по `Deploy confirmed successfully`,
   строкам обновлённых адресов и `exit 0` в журнале. Последняя строка `.bat`
   «Готово» сама по себе не подтверждает успех загрузки.

После диагностики 14.11 загрузчик обновлён: при ненулевом коде он показывает
«ОШИБКА ЗАГРУЗКИ». После успешного завершения утилиты он дополнительно
запускает `check-hosting.cjs` и сравнивает опубликованный `game.js` с локальным.
Отдельно эту проверку можно запустить файлом `ПРОВЕРИТЬ_ВЕРСИЮ.bat`.

В последней проверенной попытке журнал содержал
`22: Upload error: failed to create hosting task`, `exit 1`.
Прямая проверка dev и production подтвердила старую версию от 04.11.
Это отказ загрузки, а не подтверждение установки исправленной игры.

Альтернативный запуск из PowerShell:

```powershell
Set-Location -LiteralPath '[local-path]'
node deploy-log.js
```

`ЗАГРУЗИТЬ_В_VK.bat` предназначен для первоначальной установки. В нём осталась
старая подсказка про ID 123456; фактический ID в конфигурации уже задан правильно.
Для текущего обновления используй `ОБНОВИТЬ_В_VK.bat`.

В этой операции подготовлены только локальные файлы. Команда загрузки
на сервер VK не запускалась.
