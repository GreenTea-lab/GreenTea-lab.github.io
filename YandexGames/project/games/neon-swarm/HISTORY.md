  вместе с облачной базой через панель Sites; проект исчез из списка сайтов.
  Локальные серверные файлы, файл ключа и неиспользуемые облачные сборки удалены.
  Журнал отката: `../../catalog/neon-rating-rollback.json`.
- Проверки: `npm run test:records`, `npm run test:stories`, `npm run test:vk` пройдены.
  Подтверждены личный результат и детали забега, сохранение после перезагрузки,
  пустое состояние, мобильная компоновка, RU/EN и отсутствие внешних запросов рейтинга.
- Текущая сборка: [личный рекорд VK](deliverables/neon-swarm-vk-personal-record-2026-11-15.zip).

  Предыдущая сборка сохранена в `Desktop/neon-vk/backups/`.
