# Неоновый Рой (Neon Swarm)

Аркада-выживалка для Яндекс Игр на Phaser 3.

- `npm install` — установить зависимости
- `node build.mjs` — сборка в `dist/` (для Яндекса) и `dist-single/` (одиночный HTML для превью)
- `src/data.js` — баланс, `src/i18n.js` — тексты, `src/scenes/` — сцены игры
- `test/` — автотесты на Playwright (бот-прогон, скриншоты интерфейса)
