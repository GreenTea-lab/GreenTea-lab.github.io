# Сгенерированные фоны — 14.11.2026, версия 1.2.0

По запросу пользователя процедурные городские сцены заменены двадцатью
отдельными растровыми иллюстрациями. Использован встроенный **image_gen**,
по одному запросу на город, без API/CLI и без ключей пользователя.

## Результат

Москва, Санкт-Петербург, Париж, Амстердам, Венеция, Рим, Стамбул, Каир,
Киото, Рио-де-Жанейро, Лондон, Прага, Лиссабон, Барселона, Вена,
Марракеш, Нью-Йорк, Сингапур, Сидней и Санторини.

Все сцены выполнены в общей живописной стилистике: подробно проработанные
материалы, мягкий объёмный свет, атмосферная перспектива, растения и фактурные
элементы переднего плана. Узнаваемая архитектура — композиционный ориентир.
Это художественные виды, а не документальные фотографии или точные
географические реконструкции.

- Мастера: `art/city-backgrounds/generated/<id>.png`.
- **Точные 20 промптов и происхождение:** `art/city-backgrounds/generation.json`.
- Игровые изображения: `static/cities/<id>.webp`.
- Размер мастеров и игровых файлов: 1254×1254; WebP подготовлен с качеством
  90% без изменения размеров или композиции. Общий объём WebP — около 11,8 MiB.
- Размеры, SHA-256 и происхождение: `static/cities/manifest.json`.

Семь генераций пришлось повторить после технической ошибки сервиса;
все двадцать итоговых фонов получены и сохранены в проекте.

## Подключение

- Фоны используются в игре, меню, городских и недельных открытках.
- Телефон получает центральный вертикальный кадр; широкий игровой экран
  использует отдельный ракурс, оставляющий основной объект справа от поля.
- Код прежних городских примитивов не используется при отрисовке.
- В папочных сборках изображения подгружаются по необходимости с того же
  хостинга. В памяти хранятся не более трёх полноразмерных изображений;
  для альбома остаются небольшие миниатюры.
- Открытые миниатюры обновляются после загрузки соответствующего изображения.
- В автономный HTML встроены все фоны. Для `file:`-превью VK также создан
  `dist-vk-single/index.html`: внешние локальные картинки иначе запрещают
  Canvas экспортировать открытки из-за ограничений браузера.
- Автономный HTML теперь около 16,2 MiB; он содержит всю графику и шрифты
  и не обращается в сеть. Обычная VK-сборка оставлена с отдельными WebP,
  чтобы не скачивать все города при первом запуске на платформе.

## Проверки

- `npm run build -- postcard-mahjong` — общая, автономная, VK и автономная VK-сборки.
- `npm run test:art` — все 20 изображений, уникальность файлов, загрузка
  через автономный `file:`, смена городов, открытки, 390×844 и 1280×720,
  отсутствие сетевых запросов, ограничение кэша и автономное VK-превью.
- `npm run test:moderation` — настоящая VK/ОК-сборка через тестовый сервер,
  изображения и прежние сценарии паузы, рекламы, сохранений и первых наград.
  Платформенные ответы имитируются; реальные VK/ОК в этой работе не публиковались.
- Исходники изображений и обзор всех двадцати сцен просмотрены. Снимки игры
  и обзор: `test-results/art/`.
- `npm run verify -- --allow-edits` — общая проверка коллекции.
