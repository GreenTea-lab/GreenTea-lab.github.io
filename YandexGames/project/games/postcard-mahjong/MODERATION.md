# Маджонг с открытками — подготовка VK/ОК, 14.11.2026

Исторический отчёт первого этапа. Повторная проверка версии 1.8.1,
исправления и ограничения: [MODERATION_RECHECK.md](MODERATION_RECHECK.md).

Проверена первая игра из согласованного списка. Основа — актуальные рабочие
исходники от 11.10.2026, сохранённые при импорте. Материалы и исходные релизы
в `materials/` и `releases/` не изменялись. Загрузки на платформу и подачи
на модерацию в ходе этой работы не было.

## Замечания к «Неоновому Рою» применительно к маджонгу

| Пункт | Что обнаружено и сделано |
|---|---|
| Публикация на стену VK | В исходном маджонге социальных публикаций нет. Вызовы публикации на стену, `VKWebAppShare` и истории не добавлялись. |
| Избранное в ОК | Кнопки и вызова добавления в избранное нет ни в VK, ни в ОК. |
| Пауза после регулировки звука | Исходный сценарий на телефоне оставляет игру на паузе. Усилена изоляция окон: ввод фонового экрана недоступен, замена одного окна другим не запускает игру, правила возвращают паузу. Реальные жесты по ползункам проверены. |
| Долгий/непонятный первый цикл | Первый уровень уже содержит 12 плиток (6 пар), обучение с указателем и не имеет проигрыша по времени. Звёзды, монеты и кнопка следующего уровня есть. Первые три уровня теперь предлагают бесплатное перемешивание при отсутствии ходов. |

В численном прогоне по 1000 стартовых раскладов каждого из первых трёх уровней
случайный выбор допустимых пар давал тупик 18, 106 и 62 раза соответственно.
Это проверка генератора, а не статистика живых игроков. Бесплатное перемешивание
позволяет пройти первые шаги без траты монет, запаса помощников или рекламы.
Оно не изменяет платное перемешивание по обычной кнопке помощника.

## Дополнительные исправления

- Потеря фокуса, скрытие вкладки и события скрытия VK останавливают таймер
  и ввод. После возврата окно паузы остаётся до явного действия игрока.
- Реклама блокирует DOM, тапы по полю, таймер и автосбор. Звук выключается
  до закрытия рекламы. Повторный одновременный запрос не отправляется.
- Автоматический переход к следующей доске бесконечного режима ждёт закрытия
  паузы и возврата приложения на экран.
- В Яндекс-адаптере защита от повторных ответов исключает двойную выдачу награды.
- Окно громкости и переключатели помещаются по ширине на 320 px; низ окна
  прокручивается. Учтены безопасные области из VK Bridge и CSS `env()`.
- Ежедневный подарок и задача дня используют местную календарную дату.
  Раньше подарок переключался по UTC, а задача дня — по местному времени.
- Автономное превью больше не ждёт отсутствующий Яндекс SDK три секунды.

## Отдельная сборка VK/ОК

Ранее проект содержал только Яндекс SDK. Добавлен `src/sdk_vk.js`, который
подставляется при сборке `dist-vk/`; внешнего скрипта Яндекса в ней нет.

- Официальный `@vkontakte/vk-bridge@2.15.5` включён в JS сборки.
- `VKWebAppInit`, обработка скрытия/возврата и безопасных областей.
- Облачное хранение `VKWebAppStorageGet/Set` и резервное локальное сохранение.
  Большой прогресс делится на части по 2000 символов. Два набора ключей и
  переключение указателя после полной записи защищают предыдущую версию
  при обрыве. Записи последовательны, обычные отправки объединяются на 20 с.
- Межэкранная реклама — только на переходах, не при первом запуске и не чаще
  раза в 150 секунд. Награда за ролик выдаётся только при `result === true`.
- Локальный запуск VK-сборки не имитирует успешный просмотр рекламы.
- Покупки за деньги и общий рейтинг не подключены. Магазин сохраняет получение
  монет за ролик и покупки оформления за игровые монеты; рекорды показывают
  личный результат. Серверная оплата/общий рейтинг — отдельная работа.

Параметры сверены с типами установленной официальной библиотеки.
Совместимость VK Bridge в ОК сверена с [документацией ОК](https://apiok.ru/apps/vk).
Справочные страницы [социальных историй](https://dev.vk.com/ru/mini-apps/promotion/social-mechanics/stories)
и [правил VK](https://dev.vk.ru/ru/mini-apps-rules) в этой среде не открылись;
утверждение о полной проверке актуальных правил не делается.

## Проверки

- `npm run build -- postcard-mahjong` из корня коллекции.
- `npm run test:moderation` из папки игры: настоящая VK-сборка в Chrome,
  родитель iframe эмулирует VK Bridge. ПК 1280×720; телефон 390×844;
  ОК 320×568; горизонтальный мобильный экран 844×390 с английским языком.
  Внутренний viewport iframe проверяется отдельно, без масштабирования страницы.
- Реальные тапы и перетаскивания громкости, пауза, возврат из правил,
  потеря фокуса и события платформы, блокировка рекламы, успешный/отменённый/
  ошибочный ответ, отсутствие двойной награды.
- Сохранение всех 1000 пройденных уровней, восстановление после очистки
  localStorage, оборванная запись облака и последовательные быстрые записи.
- Первые 10 уровней пройдены реальными тапами по безопасному решению;
  первая открытка получена и видна в альбоме. Это не замер сложности/времени
  для нового игрока: тест знает решение.
- Воспроизведён тупик первого уровня; бесплатное перемешивание не тратит
  ни монеты, ни запас помощников и снова даёт доступные пары.
- `npm run test:progression`: 1000 уровней × 3 начальных значения генератора,
  все 3000 раскладов пройдены по сгенерированному решению, включая замки
  и закрытые плитки. Это не означает, что любой выбор пары приводит к победе.
- Снимки экранов просмотрены. Отчёт и снимки: `test-results/moderation/`.
- Общая проверка коллекции: `npm run verify -- --allow-edits`.

Реклама, облачные ответы и события VK в тестах эмулируются. Фактический запуск
в клиентах VK/ОК, устройства iOS/Android, реальные показы рекламы и реальное
хранилище требуют проверки в приложении перед модерацией. Одобрение по
качеству игрового цикла остаётся решением модератора.

Это предложения; перечисленные механики пока не реализованы.

| Очерёдность | Изменение | Польза и способ проверки |
|---|---|---|
| 1 | «Играть» сразу запускает первый/текущий уровень; карту оставить отдельной кнопкой | Сейчас до первого хода нужно открыть путешествие, уровень и объяснение. Сравнить долю запусков, дошедших до первой пары. |

| 2 | Недельная открытка за 3–5 ежедневных задач, с возможностью добрать пропущенные дни | Уже есть календарь, кубки и подарок. Добавить к ним конкретный коллекционный результат, не наращивая число экранов. Проверить возвращение на следующий день и завершение недели. |
| 2 | Три простых задания дня с выбором: собрать пары цветов, пройти расклад, использовать другой набор плиток | Дать разнообразные цели без требования скоростной игры и обязательных роликов. Награда — марки/оформление альбома. |
| 3 | Открытки с небольшими анимациями, рамки и фон стола за монеты | У коллекции появится индивидуальность и дополнительные цели для игровой валюты. Для начала достаточно одного города. |

Рекомендую следующую итерацию из первых четырёх пунктов: быстрый вход,
ранняя открытка, видимый прогресс и продолжение партии. Ежедневные цели
добавлять после проверки этой основы на нескольких новых игроках.
Измерять начало первой партии, завершение уровней 1/3/10, первую открытку,
возврат на следующий день и через неделю. Возвращаемость — гипотеза до таких
замеров; сбор аналитики в этой версии не подключался.
