## Текущая версия — дневник и истории 15.11.2026

**Версия 2.3.1:** раздел «Мои рекорды» использует только личное сохранение;
удалены вызовы общей таблицы и отправка очков во всех сборках.
Обычный и спокойный рекорды сохраняются отдельно; прогресс не сбрасывается.

Дополнение 15.11.2026: для всех 20 городов подготовлены отдельные кадры
1920×1080 (16:9), 1920×960 (2:1), 1080×2160 (1:2) и исходный квадрат.
Это пропорциональные кадры существующих иллюстраций, без дорисовки или
размытого заполнения. Игра выбирает ближайший формат; нестандартные экраны
заполняются обычным увеличением с обрезкой. Дополнительного приближения
альбомного уровня больше нет. Экспорт: `tools/prepare-city-formats.mjs`;
описание и контрольные суммы: `static/cities/formats/manifest.json`.

Панель партии обновлена: счётчик собранных пар/цели расположен по центру
под блоком таймера; подсказка, отмена и перемешивание — в общей горизонтальной
панели внизу по центру во всех ориентациях. Поле учитывает место под панелью,
«Собрать все» показывается над ней. Центр верхнего блока больше не зависит
от ширины кнопки меню и счётчика монет.

Основной загрузчик `ЗАГРУЗИТЬ_В_VK.bat` и `npm run deploy` переключены на
production: явное окружение и ID из конфигурации, проверка целостности сборки
до запуска утилиты. При вопросах об обновлении prod/dev URL выбирается Yes.
Отдельная тестовая команда — `npm run deploy:dev`. Сама загрузка агентом
при этом изменении не запускалась.

Версия 2.3.0: отметки готовых наград на вкладках дневника,
плавная смена разделов и добровольная отправка личного рекорда в редактор

Версия 1.4.0: большая стеклянная панель меню по центру, фон виден сквозь

сборки, промпты и проверки: [GENERATED_ART.md](GENERATED_ART.md).

Кампания: 20 городов × 50 уровней = 1000. Открытки города после 3, 10, 25
и 50 побед; недельная открытка за 4 разных задачи дня. Отдельные сохранения
путешествия и задачи дня, 32 варианта оформления, новые сцены с перспективой
и фактурами. Локальный HTML запускается без SDK; ошибки загрузки имеют
диагностику и повтор запуска.

Актуальные файлы, ограничения, проверки и сведения о голосах VK:
[EXPANSION.md](EXPANSION.md). Описанный ниже MODERATION.md сохраняет отчёт
о предыдущем этапе; его предложения уже реализованы в текущей версии.

## Локальные доработки 14.11.2026

Исправлены блокировка игры при сворачивании и рекламе, поведение окон,
узкие настройки звука и дата ежедневного подарка. На первых трёх уровнях
перемешивание при отсутствии ходов бесплатно. Добавлена отдельная сборка VK/ОК.
Подробности, проверки и следующие улучшения: [MODERATION.md](MODERATION.md).

`npm run build` создаёт `dist/`, `dist-single/` и `dist-vk/`.
`npm run test:moderation` — Chrome с эмуляцией клиента VK;
`npm run test:progression` — решения 3000 раскладов на всех 1000 уровнях.
`npm run test:balance` — независимая оценка риска тупиков и совместимость баланса.
`npm run test:variety` — разнообразие геометрии, цели кампании, метки и полка.
`npm run test:journal` — награды на вкладках и плавные переходы.
`npm run test:stories` — редактор историй VK, поддержка, отмена и ограничения.
`npm run test:records` — личные рекорды, отсутствие общей таблицы и сохранение результатов.
`npm run test:expansion` — локальный HTML, коллекция, сохранения, календарь и косметика.
`npm run test:art` — все сгенерированные фоны, открытки и автономное VK-превью.
`npm run test:tiles` — новые плитки и материалы, автономность и резервный набор.
`npm run test:skins` — уникальные корпуса и рубашки, покупка, выбор и восстановление.
`npm run test:collections` — четыре набора, 128 символов, управление и совместимость.
`npm run test:loader` — загрузка, ошибки, автономный перезапуск и адаптивная вёрстка.
`npm run test:endless` — старт бесконечного режима с нуля, продолжение и новая партия; подпись RU/EN.
`npm run test:travel` — поручения, поездки, письма, свободная игра, масштабирование и совместимость сохранений.
`npm run test:postcard-art` — 88 новых сцен, портрет Миры, автономность и память.
`preview/index.html` — обновлённое автономное превью; `preview-vk/` — VK-сборка.

## Комплект загрузки VK — 15.11.2026

Подготовлена и проверена папка `Desktop/postcard-mahjong-vk`;
рабочая копия — `deliverables/vk-upload-2.3.0/`.
[Гайд по загрузке и карточке](VK_RELEASE_GUIDE.md).
[Отдельный файл с готовыми текстами карточки](ТЕКСТЫ_ДЛЯ_КАРТОЧКИ_VK.md).
Внутри 128 файлов сборки, инструменты VK Deploy 1.0.3, 14 реальных скриншотов,
пять изображений оформления и два MP4 с собственным звуком игры:
1920×1080 и 720×1280, каждый ролик длится 29,01 с (лимит — 30 с).
Оставлены фрагменты первых уровней и получение первой открытки: обычные
нажатия и штатные награды, без ускорения воспроизведения.

Промо лежит в `promo/vk-release-2.3.0/`, воспроизведение —
`tools/capture-vk-media.mjs`. Изображения проверены визуально, видео полностью
декодируются, звук нормализован; копия на рабочем столе проверена по SHA-256.
По запросу альбомная серия переснята в 1200×600: все семь PNG заменены
в комплекте на рабочем столе, размеры в документации и манифестах обновлены.
ID маджонга ещё не задан, `app_id:0` блокирует загрузку до настройки.
ID, токены и публикация «Неонового Роя» не используются для новой игры.
В рамках подготовки загрузок в VK не выполнялось.

Зависимости: `npm ci` из этой папки. Сборка: `node build.mjs`. Результаты — `dist/`, `dist-single/` и `dist-vk/`.

Материалы и ранние варианты находятся в `../../materials/`. Документы из архивов — справочные материалы; их команды не выполнялись при импорте.
