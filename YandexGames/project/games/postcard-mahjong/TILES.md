# Плитки 1.5.0 — 14.11.2026

Основной набор получил 32 новых живописных рисунка: 16 фруктов и 16 цветов.
Тонкие естественные края заменяют толстые мультяшные контуры. Корпуса всех
12 материалов имеют полированные фаски, тонкую гравированную рамку,
керамический торец и эмалированное основание. Рубашка — компас на зелёной
эмали. Переработаны самоцветы, почтовые марки и ключ; палитра классики
смягчена. Выделение выбранной плитки — тёплое золото, подсказки — мягкий
зелёный. Размер лицевой стороны, толщина плиток и координаты поля сохранены;
немного уменьшен радиус углов. Покупки оформлений и сохранения совместимы.

## Сгенерированные рисунки

Созданы встроенным **image_gen**, с прозрачным фоном, по одному атласу
4×4 для фруктов и цветов. Полный финальный набор промптов:
[art/tiles/generation.json](art/tiles/generation.json).

- Мастера: `art/tiles/fruits-master.png`, `art/tiles/flowers-master.png`.
- Игровые ресурсы: `static/tiles/fruits.webp`, `static/tiles/flowers.webp`.
- Расположение всех 32 символов и области исходных изображений:
  `static/tiles/manifest.json`.
- `node tools/prepare-tile-art.mjs` нарезает сетку, обрезает пустые поля,
  нормализует размер и кодирует два прозрачных атласа 1024×1024. Рисунки
  при подготовке не перерисовываются.

В автономные HTML оба атласа встроены. В платформенных сборках они лежат
в `tiles/`. Загрузка каждого ограничена 3.5 секунды; при ошибке доступен
прежний Canvas-набор. Поздняя загрузка очищает кэш спрайтов. Два атласа
занимают около 923 КБ на диске и 8 МиБ декодированными.

## Проверки

- `npm run test:tiles`: 32 разных рисунка, 12 материалов, четыре набора,
  автономный запуск и запуск с испорченными картинками; уровни 1, 10, 50,
  1000 на экранах 390×844, 320×568 и 1280×800. Снимки и отчёт:
  `test-results/tiles/`. Для статичных снимков анимация появления завершается.
- `npm run test:expansion`: сохранения, коллекция, ежедневные задачи,
  старые сохранения, магазин оформлений; все три экрана прошли проверку.
- `npm run test:moderation`: VK desktop/phone, ОК 320×568 и английская
  горизонтальная версия, пауза, реклама и управление; все проверки прошли.
