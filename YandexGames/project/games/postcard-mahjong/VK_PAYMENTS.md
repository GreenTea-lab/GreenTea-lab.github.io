# Голоса VK: результат исследования 14.11.2026

В этой версии реальные платежи **не включены**. Условие «если это легко»
не выполняется для текущего проекта: он целиком статический, без серверной
части, платёжного адреса обратного вызова и базы заказов.

В [официальном примере VK](https://github.com/VKCOM/vk-direct-games-example/blob/master/README.md#внутриигровые-покупки)
указано, что покупка предметов запускается через `VKWebAppShowOrderBox`,
а для работы необходимо настроить обработчик обратных вызовов и его URL
в настройках платежей приложения. Клиентские типы метода также присутствуют
в установленном официальном `@vkontakte/vk-bridge@2.15.5`.

Страницы dev.vk.com с подробным протоколом платежей в этой среде не открылись.
Поэтому точную схему актуальных уведомлений и поддержку каждой мобильной
платформы нужно подтвердить по доступной документации/консоли VK перед
реальным включением. Отдельно проверяется поведение в ОК.

## Минимальная полноценная интеграция

1. Настроить приложение и каталог товаров/платёжные параметры в VK.
2. Развернуть HTTPS-обработчик платформенных уведомлений. Секрет приложения
   хранить только на сервере; проверять подлинность входящих запросов.
3. Сохранять заказы в постоянной базе, выдавать покупку один раз на заказ,
   поддерживать восстановление купленного после перезапуска/смены устройства.
4. Связать серверные права/баланс с игровым сохранением. Простое добавление
   монет после положительного ответа браузера не заменяет эту часть.
5. Проверить тестовую оплату, отмену, повтор уведомления, потерю сети,
   перезагрузку во время покупки и восстановление на другом устройстве.

Для первого подключения предлагаю три товара: набор монет, постоянное
отключение межэкранной рекламы и набор косметики. Цены в голосах пока
не назначались. Все новые оформления сейчас покупаются только за игровые
монеты; карта и награды доступны без оплаты.

Никакие платежи, доступы, денежные операции или изменения настроек приложения
при этой работе не выполнялись. Новая кнопка с неработающей оплатой не добавлена.
