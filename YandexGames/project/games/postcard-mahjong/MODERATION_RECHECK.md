# Повторная проверка VK/ОК · 14.11.2026 · версия 1.8.1

Исторический отчёт. В версии 2.3 добавлен добровольный рекорд в истории VK;
актуальное поведение и ограничения: [JOURNAL_AND_STORIES.md](JOURNAL_AND_STORIES.md).

Проверена текущая игра после обновления графики, коллекций и загрузчика.
Исправлены рекламные предложения и гонка возобновления звука. Добавлены
диагностика неподдерживаемого браузера и лицензии в сборках.
Подготовлен локальный релиз; загрузка в кабинет и подача на модерацию не выполнялись.

## Замечания модерации «Неонового Роя»

| Замечание | Результат проверки маджонга |
|---|---|
| Постинг на стену VK больше не поддерживается | Кнопок публикации и вызовов WallPost, Share, Story в игровой интеграции нет. Журнал Bridge в браузерных сценариях также не содержит таких запросов. Истории не добавлялись. |
| «Добавить в избранное» не работает в ОК | Кнопки и запроса Favorites нет. |
| Громкость снимает игру с паузы в фоне | Реальные жесты мышью и эмулированным касанием по ползунку, нажатия вне окна и попытка ввода по canvas оставляют таймер, поле и gameplay остановленными. Правила возвращают паузу. Возврат VK сам её не закрывает. |
| Слишком длинный первый цикл | Старт — 6 пар с обучением, без проигрыша по таймеру. После победы видны монеты, звёзды, штампы и следующий уровень. Первая открытка после 3 побед, следующая после 10. Первые три уровня дают бесплатное перемешивание при тупике. |

Тест с известным решением подтверждает проходимость и награды, но не измеряет
интерес или время прохождения новым игроком. Оценка качества цикла остаётся
за модератором.

## Исправления этого этапа

1. Ранее ответ CheckNativeAds игнорировался. Теперь предложения роликов
   показываются после положительного ответа и скрываются при false, ошибке
   или отсутствии ответа. Перед показом выполняется повторная проверка.
   В ОК NativeAds выключены вне Android-клиента согласно опубликованной
   таблице совместимости. Магазин без рекламы объясняет игровые способы
   получения монет; обычный ежедневный подарок продолжает работать.
2. Проверка наличия ролика ограничена 5 секундами. У открытого ролика
   короткого тайм-аута нет: поле, ввод, таймер и звук остановлены до ответа
   платформы. Награда — только за result === true. Повторный запрос
   блокируется. Межэкранная реклама — на переходах с интервалом 150 секунд;
   флаг «Без рекламы» учитывается.
3. Воспроизведена гонка WebAudio: старый незавершённый resume() мог включить
   звук поверх следующей рекламы. После завершения resume теперь повторно
   проверяются причины остановки и контекст приостанавливается при необходимости.
4. При отсутствии необходимых API или Canvas 2D загрузчик предлагает обновить
   браузер/приложение, игра не инициализируется. Есть RU/EN и повтор запуска;
   кнопка офлайн в таком случае скрыта. Сборка использует синтаксис ES2019.
5. OFL для Nunito, Kurale и Lobster включены в HTML и THIRD_PARTY_NOTICES.txt.
   VK-сборка также содержит MIT License установленного VK Bridge.
   Файлы WOFF2 из исходного проекта не заменялись.

## Документация и ограничения проверки

- [VK Bridge в ОК](https://apiok.ru/apps/vk): сверены параметры запуска,
  ограничения Favorites, NativeAds и платежей, Storage и события скрытия.
  Раздел порядка публикации помечен устаревшим и не используется как
  действующая инструкция регистрации.
- [Официальный VK Bridge](https://github.com/VKCOM/vk-bridge): контракты
  сверены с исходниками и установленными типами 2.15.5. CheckNativeAds
  возвращает boolean, успешный ShowNativeAds — result === true.
- [Документация запуска ОК](https://apiok.ru/apps/rules) и размещённые там
  [правила платформы](https://apiok.ru/res/files/apps/OK_platform_rules_EN.pdf):
  проверены работающая версия, понятные функции, русский интерфейс,
  отсутствие принудительных социальных действий, внешних оплат и запросов
  персональных данных. В документе есть старые положения; он не заменяет
  актуальные правила новой платформы VK.
- [Мобильные HTML5-игры ОК](https://apiok.ru/apps/game_setup/instant_games):
  проверены локальная адаптивность, касания, ориентации и сообщение
  неподдерживаемому браузеру. Скорость на физических iPhone/Nexus не измерялась.
- **Полный актуальный текст [правил VK](https://dev.vk.ru/ru/mini-apps-rules)
  не получен:** доступ заблокирован политикой безопасности браузера.
  Полная проверка всех пунктов текущей редакции и соответствие ей
  **не заявляются**. Замечания из переписки модератора учтены непосредственно.

## Дополнительные проверки проекта

- VK-архив содержит VK Bridge, локальные изображения, шрифты и JS;
  внешнего Яндекс SDK нет. Автономные HTML запускаются без сети.
- Пауза при blur, скрытии вкладки, событиях VK; безопасные области экрана.
- Точные сохранения путешествия/задачи дня, продолжение, миграция старого
  прогресса и восстановление допустимых повреждённых данных.
- Облако всех 1000 уровней: части по 2000 символов, последовательная запись,
  предыдущая версия при обрыве, восстановление после очистки localStorage.
- 20 городов × 50 уровней; 3000 раскладов пройдены по генераторному решению.
  Первая/недельная открытки, наверстывание, отсутствие повторной недельной
  награды, покупка и восстановление косметики за игровые монеты.
- Все 20 фонов, четыре набора рисунков, 12 материалов и 12 рубашек;
  резервная графика при отсутствии необязательных изображений.
- Задержка загрузки, отсутствующий JS, повтор офлайн, RU/EN, reduced motion;
  фиктивных процентов нет.
- Голоса и денежные покупки VK/ОК выключены, денежных товаров нет.
  Рекорды обозначены как личные. Игра не делает публикаций, приглашений
  и рассылок от имени пользователя.

## Воспроизведение

Из папки игры: `npm run build`, затем `npm run test:moderation`,
`test:progression`, `test:expansion`, `test:art`, `test:tiles`, `test:skins`,
`test:collections`, `test:loader` — каждый с префиксом `npm run`.
Из корня: `npm run verify -- --allow-edits`.

Семь конфигураций: VK Web, Android, iOS, Mob.Web landscape EN;
ОК iOS 320×568, Web и Android. Ещё шесть сценариев проверяют false/error/timeout
при первоначальном предложении и после него. Длительный рекламный ответ
удерживается более 5 секунд, проверяются таймер и AudioContext.
Это Chrome с эмуляцией Bridge, а не реальные приложения iOS/Android.
Рекламные и облачные ответы в тестах эмулируются.

Отчёты и снимки: `test-results/<название проверки>/`.
Проверка коллекции: `../../catalog/verification.json`.

Итог 14.11.2026: все восемь проверок игры прошли. `test:moderation` —
7 конфигураций и 6 отрицательных рекламных сценариев, без pageerror;
`test:progression` — 3000 из 3000 раскладов. Проверка коллекции также прошла:
2730 файлов материалов неизменны, 510 модулей проверены, 28 HTML-страниц
отвечают по HTTP, ошибок нет. Это разные области проверки; общая проверка
коллекции сама по себе не является игровым тестом.

   ОК требуют поддержку пользователей и монетизацию; реальные рекламные
