# Баланс сложности — 2.1.0, 15.11.2026

Исторический отчёт этапа 2.1. Актуальная версия 2.2 с новыми полями,
целями и повторной калибровкой описана в [VARIETY.md](VARIETY.md).

Кампания остаётся из 1000 уровней: 20 городов по 50. Переработаны геометрия,
повторы рисунков, порядок знакомства с механиками и выбор конкретной раздачи.

## Начало и ритм

- Первые 11 уровней: один рисунок ровно на одной паре. Любой допустимый выбор
  пары сохраняет решение. Размеры первых десяти полей: 6, 9, 12, 11, 10, 14,
  17, 17, 19, 19 пар. Прежнего скачка до 33 пар на десятом уровне нет.
- Первая открытка по-прежнему после трёх побед. С 4-го уровня — монетки.
- На 12-м уровне объясняются повторяющиеся рисунки: сначала до двух пар
  одного вида, на сложных раскладах — до трёх. При выборе нужно учитывать,
  какие плитки освобождаются снизу и по бокам.
- На 17-м уровне вводятся два замка, на 26-м — три скрытые плитки.
  Эти два знакомства проходят на лёгких полях без неоднозначного выбора пар.
- В первом городе 20 лёгких, 18 обычных и 12 сложных уровней. Размер поля
  постепенно доходит до 33 пар в финале.
- Начиная со второго города в каждой десятке: легко, обычно, обычно, сложно,
  легко, обычно, обычно, сложно, обычно, сложно. Итого 10/25/15 на город.
  Количество пар и глубина растут с продвижением; передышки остаются до конца.
- Финалы городов имеют 33–50 пар и 3–4 слоя. Уровень 1000 — большая фигура
  из 50 пар в четыре слоя вместо прежнего маленького поля.
- На карте и в стартовой подписи указана сложность. Свободная игра тоже
  различает ступени количеством повторов, включая маленькие фигуры.

## Проверка раздач

Для каждого уровня сохранены три проверенные раздачи. Обычный запуск выбирает
одну из них; незавершённая партия восстанавливает точное состояние. Подбора
сложности по тратам или проигрышам игрока нет.

`node tools/balance-campaign.mjs` проверил 8372 кандидата и сохранил 3000 раздач
в `src/campaign-seeds.js`. Для оценки риска тупика симулятор выбирает случайную
доступную пару без планирования, подсказок, отмены и перемешивания.
При отборе каждая обычная/сложная раздача прошла 96 подтверждающих прогонов;
выбранные варианты попали в заданные диапазоны. Затем отдельная проверка
с независимыми случайными последовательностями выполнила ещё 64 прогона
для каждой из 3000 раздач — всего 192000.

| Часть кампании | Легко | Обычно | Сложно |
| --- | ---: | ---: | ---: |
| Первый город, случайные действия | 100% | 85,4% | 54,9% |
| Остальные города, случайные действия | 100% | 73,8% | 40,6% |

Это доля завершений **симулятора**, не процент побед реальных игроков.
Скрытые рисунки автоматически открываются, когда плитка становится свободной;
тест учитывает доступность ходов и замки, но не измеряет скорость зрительного
поиска, удобство картинки или память человека. Для всех 3000 раздач отдельно
проверено полное решение с реальными ключами, замками и раскрытием плиток.
Число замков и скрытых плиток проверено при каждой раздаче, включая обучение.

Пороги времени для звёзд учитывают размер, глубину, скрытые плитки, замки
и повторяющиеся пары. Они пока расчётные: для окончательной настройки нужны
наблюдения за живыми игроками. Спокойный режим продолжает давать три звезды
без ограничений по времени и не меняет выбранный уровень сложности.

## Сохранения

Пройденные уровни, звёзды, монеты, открытки и настройки сохраняются. Начатый
до обновления уровень восстанавливает свои плитки, историю ходов, таймер
и старые пороги звёзд. Его повторные сохранения помечаются `balanceVersion:2`.
Новые партии используют `balanceVersion:3`. Перезапуск старого поля начинает
новый сбалансированный вариант. `campaignVersion:2` в общем сохранении оставлен
без изменения: это отдельная миграция старой коллекции, запускать её заново нельзя.

## Воспроизведение проверок

- `npm run test:balance`: контроль конфигурации каталога, независимая оценка
  риска, точные количества механик, RU/EN и четыре размера экрана,
  новая раздача, обучение, точное продолжение новых и старых партий, звёзды.
- `npm run test:progression`: все 1000 уровней × три решения.
- `npm run test:travel`, `test:expansion`, `test:endless`: поездки, свободные
  расклады, задания, награды, сохранения и бесконечный режим.
- `npm run test:moderation`: эмуляция VK/ОК, пауза/звук/реклама, облако,
  восстановление тупиковой старой партии и бесплатное перемешивание на старте.

Подробные отчёты и снимки создаются в `test-results/balance/`.
При изменении генератора нужно заново выполнить калибровку: проверка хеша
конфигурации обнаруживает устаревший каталог раздач.

Сборка подготовлена локально. Загрузки в VK/ОК в рамках этой работы не было.

Проверки `balance`, `progression`, `travel`, `expansion`, `moderation`, `endless`
и `loader` прошли. Ответы платформ в тесте модерации эмулированы;
проверка в настоящем клиенте VK/ОК остаётся отдельным этапом.
