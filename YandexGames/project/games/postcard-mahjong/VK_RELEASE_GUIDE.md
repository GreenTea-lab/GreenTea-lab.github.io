# Маджонг с открытками — загрузка в VK и заполнение карточки

Подготовлено 15.11.2026, версия игры **2.3.1**. Это комплект для самостоятельной
загрузки, по структуре как `neon-vk`. Игра ещё не загружалась и не публиковалась
в рамках подготовки этой папки. ID приложения маджонга пока не указан.

## 1. Содержимое папки

| Файл / папка | Назначение |
| --- | --- |
| `build/` | Только эти файлы загружаются на хостинг VK: `index.html` в корне, JS, изображения, шрифты, лицензии |
| `vk-hosting-config.json` | Папка сборки, ID приложения и точки входа Web / Mob.Web / Android / iOS |
| `ЗАГРУЗИТЬ_В_VK.bat` | Обычная выкладка production с обновлением основных URL; запросит ID игры, если он не задан |
| `ПРОВЕРИТЬ_СБОРКУ.bat` | Проверка целостности 128 файлов сборки без подключения к VK |
| `package.json`, `package-lock.json` | Официальная утилита `@vkontakte/vk-miniapps-deploy` 1.0.3 |
| `media/screenshots/portrait/` | 7 реальных вертикальных скриншотов, 600 × 1200 |
| `media/screenshots/landscape/` | Те же 7 сюжетов, 1200 × 600 |
| `media/video/` | Горизонтальное и вертикальное MP4 с реальным геймплеем и звуком игры, каждое меньше 30 секунд |
| `media/branding/` | Иконки 576, 278, 150, 32 px и обложка 1120 × 630 |
| `media/МАТЕРИАЛЫ.md` | Порядок кадров и сведения о записи; медиа сняты в 2.3.0, механика актуальна, пункт «Рекорды» теперь называется «Мои рекорды» |
| `preview.html` | Автономная локальная проверка; не заменяет `build/` |
| `archives/` | Сохранённые ZIP сборки VK/ОК и исходников |

Видео и промоматериалы лежат **вне `build/`**: утилита отправляет только игровую
сборку. Исходный код и инструкции на игровой хостинг тоже не отправляются.

## 2. Создать или выбрать приложение

1. Открой кабинет разработчика VK под своим аккаунтом. Найди раздел игр / своих
   приложений. Названия пунктов в текущем кабинете могут отличаться.
2. Если «Маджонг с открытками» уже создан, открой **его**. Если нет — создай
   отдельную игру. Приложение «Неонового Роя» для этого не используй.
3. Скопируй числовой ID из настроек приложения.
4. Добавь тестировщиков в администраторы / список тестирования, если кабинет
   ограничивает доступ к черновику.
5. Заранее подготовь действующий контакт поддержки: свою почту или сообщество VK.
   Реквизиты владельца, статус разработчика и поля для iOS заполняй по реальным
   данным и актуальным подсказкам кабинета.

## 3. Один раз настроить папку

Нужен Node.js 18 или новее с npm. Установленный на компьютере Node.js 24 подходит.
Открой терминал в этой папке — удобно нажать правой кнопкой в пустом месте
Проводника и выбрать открытие терминала.

```powershell
npm run setup
npm run check
```

Первая команда спросит ID маджонга и запишет его в `vk-hosting-config.json`.
Изначально там `app_id: 0` — это заглушка, загрузка с ней блокируется.
ID «Неонового Роя» также блокируется, чтобы случайно не заменить другую игру.

Остальная конфигурация уже готова:

```json
{
  "static_path": "build",
  "app_id": 0,
  "endpoints": {
    "mobile": "index.html",
    "web": "index.html",
    "mvk": "index.html"
  }
}
```

`mobile` используется для мобильных клиентов, `web` для полной версии,
`mvk` для мобильного сайта. Одна адаптивная игра обслуживает все три входа.

Если папки `node_modules` нет или установка инструментов была удалена:

```powershell
npm ci --ignore-scripts --no-audit --no-fund
```

Готовая игра не требует сборки на твоём компьютере: файлы `build/` уже собраны.

## 4. Обычная выкладка в VK

Запусти `ЗАГРУЗИТЬ_В_VK.bat` или из терминала:

```powershell
npm run deploy
```

Команда явно устанавливает `MINI_APPS_ENVIRONMENT=production` только для запуска
утилиты и использует ID из `vk-hosting-config.json`. Ранее установленный в
терминале `dev` не переключит эту команду на тестовую загрузку.
Утилита может открыть процедуру авторизации / запросить подтверждение VK.
Следуй её сообщениям. Авторизация выполняется у себя, токены никому не отправляй.

Утилита 1.0.3 спрашивает, какие адреса обновить. Для обычной выкладки:

- `Would you like to deploy ...?` → **Yes**.
- `Would you like to update prod urls?` → **Yes**.
- `Would you like to update dev urls?` → **Yes**.
- `Would you like to update test group url?` → **No**, если отдельной группы нет.

Проверь, что в выводе указан именно ID маджонга. Сохрани выданные HTTPS-адреса
мобильного приложения, Web и Mob.Web. Если адреса не подставились автоматически,
занеси их в основные поля URL размещения в кабинете. Для запуска обычной версии
выключи «Режим разработки» в соответствующих разделах и сохрани настройки.

Для отдельной тестовой загрузки остаётся `npm run deploy:dev`; она использует
только dev-окружение. `npm run deploy:prod` равнозначна основной команде.

Открой приложение через VK как разработчик. Локальный `preview.html` не проверяет
настоящее облако, объявления или редактор историй.

## 5. Заполнение карточки — готовые тексты

Числовые лимиты и обязательные поля сверяй с текущим кабинетом. Приведённые
ниже тексты намеренно короткие; старые лимиты из инструкции «Неонового Роя»
не считаются подтверждённой текущей редакцией требований.

**Название:**

> Маджонг с открытками

**Английское название, если поле требуется:**

> Postcard Mahjong

**Слоган:**

> Находите пары. Собирайте города.

**Короткое описание:**

> Уютный маджонг: 1000 уровней, 20 городов и коллекция красивых открыток.

**Полное описание:**

> Отправляйтесь в неспешное путешествие по городам мира! Находите одинаковые
> свободные плитки, открывайте новые расклады и собирайте альбом открыток.
>
> Вас ждут 1000 уровней в 20 городах, классические партии, почтовые маршруты,
> тайные печати и задания с ключами. Первую открытку можно получить уже после
> трёх побед. Заглядывайте в задачу дня, выполняйте почтовые поручения и собирайте
> недельные открытки. Пропущенные ежедневные задачи можно наверстать.
>
> Выбирайте рисунки и материалы плиток, сохраняйте любимые расклады, увеличивайте
> поле и продолжайте незавершённую партию. В спокойном режиме можно играть
> без спешки: время не уменьшает награду за завершение.
>
> Новые виды городов и маленькие путешествия ждут вас в «Маджонге с открытками»!

**Как играть, если есть отдельное поле:**

> Нажмите на две плитки с одинаковым рисунком. Плитку можно взять, если сверху
> её ничто не закрывает и свободна хотя бы одна боковая сторона. В обычном
> раскладе снимите все пары. В специальных заданиях выполните цель над полем
> и соберите указанное количество пар. Подсказка поможет найти ход, отмена —
> вернуть предыдущую пару, перемешивание — продолжить игру в тупике.

**Рекомендуемый жанр:** головоломки / настольные / маджонг — выбери ближайший
из реально доступных пунктов. **Возрастная маркировка:** заполни анкету площадки
по фактическому содержанию; готовое решение модератора здесь не подставляется.

**Платформы:** Web, Mob.Web, Android и iOS — только после собственной проверки
в заявленных клиентах. **Языки:** русский и английский. **Управление:** мышь
или касание; увеличение поля кнопками и жестом двумя пальцами.

**Адрес приложения:** можно попробовать `postcard_mahjong`, если он доступен
и соответствует текущим правилам адресов. Доступность имени не проверялась.

## 6. Какие картинки и видео прикреплять

1. Начни с `media/branding/icon-576.png`; остальные размеры даны на случай
   отдельных полей. `icon-32.png` — favicon. Если кабинет требует другой размер,
   используй крупный исходный вариант, а не растягивай маленький.
2. `cover-1120x630.png` — обложка / большой сниппет. Это оформление карточки,
   а не скриншот игрового процесса.
3. Для вертикальной галереи загружай одну серию из `screenshots/portrait/`.
   Для горизонтальной — серию из `screenshots/landscape/`. Внутри каждой серии
   все кадры одинакового размера. Не смешивай ориентации в одном наборе.
4. Для первых мест рекомендуются 01 «Москва», 02 «Париж», 03 «Киото».
   Затем 04 «Венеция», 05 «Открытка», 06 «Дневник», 07 «Карта».
5. Для поля видео выбери соответствующее MP4 в `media/video/`.
   Если кабинет принимает ссылку вместо файла, самостоятельно загрузи ролик
   в VK Видео и вставь ссылку. Автоматической загрузки видео не выполнялось.

Размеры файлов подготовлены как практические варианты. Обязательные размеры,
лимиты веса и способ добавления видео окончательно определяет текущий кабинет.
Не переноси требования VK Play на VK Игры: это разные интерфейсы размещения.

## 7. Монетизация, рекорды и сохранения

- Денежных покупок за голоса VK или ОКи **в этой сборке нет**. Не заводи товары,
  которые обещают выдать валюту или «Без рекламы»: серверная выдача не подключена.
- Реклама использует VK Bridge. Проверка наличия объявления предшествует
  показу; межэкранные объявления идут на переходах с интервалом 150 с.
  Ролики за награду доступны только по явному нажатию. Возможность монетизации,
  настройки кабинета и реальные показы проверь в своём приложении.
- «Мои рекорды» — только личные результаты обычного и спокойного режимов.
  Получения общей таблицы, отправки очков и входа ради рейтинга нет ни в одной сборке.
  Рекорды сохраняются в собственном прогрессе игрока. Ненулевой рекорд можно
  отправить в редактор историй поддерживаемого клиента VK. В локальном HTML,
  ОК и при отсутствии поддержки кнопка скрыта. Публикацию выбирает игрок.
- Сохранение дублируется локально и в хранилище платформы. Отдельно сохраняются
  путешествие, задача дня, поездка, свободная партия и бесконечный забег.

## 8. Проверка на устройствах перед подачей

Проверь в своём приложении: старт с мобильной сети, первые три победы и открытку,
закрытие и повторное открытие незавершённого поля, переход между устройствами,
сворачивание и возврат, паузу после регулировки звука, объявления и отмену ролика.
Отдельно проверь истории на поддерживаемом VK-клиенте и отсутствие кнопки в ОК.
Подготовленные автоматические проверки использовали эмуляцию ответов платформы.

Заполни действующий контакт поддержки, сведения о разработчике и требуемые
кабинетом документы. Сверь актуальные правила и права на публикуемую основу
и материалы. Лицензии шрифтов и VK Bridge включены в сборку; история создания
новой графики сохранена в исходном проекте. Полная текущая редакция правил VK
инструментом подготовки не получена; одобрение модерации не гарантируется.

## 9. Production и заявка на модерацию

Для повторной выкладки:

```powershell
npm run check
npm run deploy
```

Основная команда всегда выбирает production независимо от переменной в терминале.
`deploy:dev` остаётся отдельной тестовой командой. Обе устанавливают окружение
только своему процессу. В обычной выкладке выбери обновление prod-адресов **Yes**
и dev-адресов **Yes**. Проверь итоговые адреса в настройках размещения.

Само размещение файлов, включение приложения и подача в каталог — отдельные
действия. Открой раздел модерации кабинета, проверь заполнение карточки,
выбери только проверенные платформы и отправь заявку.

**Текст для модератора, после реальной проверки своего приложения:**

> Здравствуйте! Подготовили «Маджонг с открытками» для проверки.
> Начало — короткие обучающие расклады, первая открытка после трёх побед.
> В кампании 1000 уровней и 20 городов, есть задача дня и продолжение партий.
> Публикации на стену и добавления в избранное платформы нет.
> «Рекорд в историю» открывает редактор VK с изображением и ссылкой на игру
> только по нажатию игрока; в неподдерживаемых клиентах и ОК кнопка скрыта.
> Окна настроек и громкости сохраняют паузу. Реклама — через VK Bridge;
> денежные покупки в этой версии отключены.

Не добавляй к сообщению утверждение о проверке устройств, на которых сам
не проверял игру. Ссылку на поддержку и данные приложения добавь свои.

## 10. Источники и обновления

Структура конфигурации и команды сверены с официальным
[VK Mini Apps Deploy](https://github.com/VKCOM/vk-miniapps-deploy) и установленной
версией 1.0.3, уже используемой в папке «Неонового Роя». Смена dev / production
описана там же. Никакие ID, токены или история авторизации из «Неонового Роя»
в эту папку не переносились.

При следующем обновлении заменяй `build/` целиком подготовленной новой сборкой
и обновляй контрольный `release-manifest.json` вместе с ней. Сохраняй ID маджонга.
Старые файлы из `build/` предыдущей версии не смешивай с новой игрой.
