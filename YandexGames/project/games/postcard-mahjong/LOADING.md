# Экран загрузки 1.8.0 — 14.11.2026

В 1.8.1 добавлено сообщение для неподдерживаемого браузера:
[повторная проверка релиза](MODERATION_RECHECK.md).

Стеклянная панель с двойной латунной окантовкой, городским фоном,
эмблемой и тремя настоящими плитками из игры. Плитки слегка покачиваются,
по золотой полосе проходит блик. Показаны масштаб путешествия и текущий
этап запуска: оформление, сохранение, городской вид.

Полоса неопределённая: проценты загрузки не вычисляются и не показываются.
Искусственной задержки перед игрой нет. На телефоне содержимое идёт одной
колонкой, на низком горизонтальном экране — двумя внутри общей панели.
Предпочтение уменьшенной анимации учитывается. Тексты доступны на RU/EN.

## Ресурсы

Новые генерации изображений не потребовались: используются городская
живопись, существующая эмблема и реальные игровые спрайты.

- `static/ui/loader-city.webp` — облегчённый вид Москвы.
- `static/ui/loader-apple.webp` — эмалевое яблоко на слоновой кости.
- `static/ui/loader-bamboo.webp` — нефритовая рубашка.
- `static/ui/loader-flower.webp` — василёк на синем фарфоре.
- `static/ui/emblem.webp` — существующая эмблема.
- `static/loader.css` — адаптивное оформление и анимация.

`node tools/prepare-loader-art.mjs` экспортирует загрузочные плитки из
актуальной `dist-single/index.html`. После изменения основной графики:
собрать игру, выполнить этот скрипт и собрать повторно. В автономных HTML
все пять ресурсов встроены и не требуют внешнего соединения.

## Поведение и проверки

Сохранены диагностика отсутствующих файлов, таймер задержки 12 секунд,
кнопки «Повторить» и «Открыть без сети». В состоянии ошибки анимация
останавливается, текст получает роль оповещения. Ошибка необязательной
картинки не объявляется ошибкой запуска всей игры. При нормальном запуске
экран удаляется перед уведомлением платформы о готовности.

`npm run test:loader` проверяет загрузку и ошибку при 1280×800, 390×844,
320×568, 844×390 и английском 320×568; готовность картинок, отсутствие
фиктивных процентов, уменьшенную анимацию, настоящий таймер задержки,
перезапуск без сети, отсутствующий `game.js` и нормальный запуск двух
автономных сборок. Снимки и отчёт: `test-results/loader/`.

`npm run test:moderation` проверяет запуск и игровые сценарии через
эмуляцию VK/ОК на четырёх экранах.
