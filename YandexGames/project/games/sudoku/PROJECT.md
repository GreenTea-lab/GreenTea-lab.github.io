# Судоку. Дзен-сад

Текущая подготовка: **1.1.0 от 17.11.2026**. Подробности, сравнение конкурентов,
проверка 1000 уровней и ограничения модерации — в [RELEASE.md](RELEASE.md).
`npm run build`, `npm run test:levels`, `node test/runtime.mjs`.
Браузерные тесты — только удалённо с `GAME_TESTS_REMOTE=1`.

Судоку в спокойном дзен-саду

- Рабочий код: `src`.
- Дата последнего файла исходного кода: 2026-10-11.
- Превью: `preview/index.html` (2026-10-12).
- Источник: `ВСЕ_ИГРЫ.zip!/ВСЕ_ИГРЫ/sudoku/sudoku-source.zip`.
- Последний найденный автономный HTML. Дата упаковки превью не означает новую версию игровой логики.

Зависимости: `npm ci` из этой папки. Сборка: `node build.mjs`. Результаты — `dist/` и `dist-single/`; у Neon Swarm также `dist-vk/`.

Материалы и ранние варианты находятся в `../../materials/`. Документы из архивов — справочные материалы; их команды не выполнялись при импорте.
