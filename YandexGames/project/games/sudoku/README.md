# Судоку. Дзен-сад / Zen Garden Sudoku

Судоку для Яндекс Игр в стилистике японского сада: крупные цифры, три размера текста, темы «Ночь», «Рассвет» и «Контраст», RU и EN.

- «Путь садов»: 1000 уровней в 20 садах по 50, сложность растёт пилой; каждый 10-й уровень — диагональное судоку, в первых садах разминки 6×6;
- быстрая игра (классика 6 уровней сложности, диагональ 4, мини 6×6 2) и судоку дня с календарём и серией; бесконечно за счёт преобразований, сохраняющих единственность и сложность;
- все головоломки с единственным решением и решаются логикой; сложность оценивается решателем по приёмам (одиночки → пересечения и пары → тройки и X-Wing → XY/XYZ-Wing, Swordfish, четвёрки);
- умная подсказка объясняет ход словами и подсвечивает клетки; обучение на первом уровне с кнопкой «Пропустить обучение»;
- «Мой сад»: 48 предметов в четырёх сезонах; 24 достижения; рекорды и статистика;
- Yandex Games SDK: облачные сохранения (`sudoku_zen_save_v2`), полноэкранная и наградная реклама, лидерборд `score`, покупки `coins_1000/3500/10000` и `disable_ads` (плюс `coins_300/3000` прошлой версии); прогресс прошлой версии переносится автоматически;
- монетизация: межстраничная реклама в паузах, награды за рекламу (×2 за победу, +50 монет, подарок дня ×3, сохранение серии), стили поля за монеты, «Сад мастера» (`premium_pass`);
- музыка: генеративные пьесы для кото в японских пентатониках с колокольчиками, каплями и ручьём (`src/zen.js`), три настроения;
- процедурная графика (canvas, SVG), музыка и звуки (Web Audio), без внешних ресурсов.

## Сборка

```
npm ci
node tools/genpuzzles.mjs   # головоломки -> src/data/puzzles.json (около 2 минут, всё проверяется)
node build.mjs              # dist/ (для консоли) и dist-single/index.html (один файл)
./tools/pack.sh [имя] [папка]   # архивы <имя>-yandex.zip, <имя>-source.zip и inapps/ (по умолчанию sudoku, release/)
```

## Тесты

```
node test/ui.mjs [phone|desk|small|tablet]  # скриншоты экранов в test/out/, ищет сырые ключи перевода
node test/themes.mjs        # три размера текста и три темы, проверка, что ничего не вылезает за экран
node test/flow.mjs          # интеграция с моком SDK: запуск, обучение, подсказки, пауза, сохранения, реклама, покупки, судоку дня, EN
node test/levels.mjs        # открывает все 1000 уровней, пулы и 60 ежедневных; бот решает каждый 10-й уровень подсказками
node test/migrate.mjs, test/ranks.mjs       # перенос прогресса прошлой версии (облако и localStorage), старые ID покупок
node tools/music_audit.mjs  # все ноты в ладу, без писка, скачков и долгой тишины
node tools/render_music.mjs [папка] [сек]  # примеры музыки в WAV
node promo/inapps.mjs [папка]  # иконки покупок 256×256 и inapps.csv
```

Инструкция по публикации: `КАК_ОПУБЛИКОВАТЬ.md` рядом с архивами.
