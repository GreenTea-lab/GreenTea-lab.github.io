# Загрузка «Блоков у камина» в VK

Комплект версии 2.5.0, 15.11.2026. Подготовка локальная: загрузка на хостинг и публикация не выполнялись.

1. Создайте отдельное приложение для «Блоков у камина» в кабинете VK либо откройте уже созданное приложение этой игры. Не используйте ID «Неонового Роя» или маджонга.
2. В папке комплекта запустите `ПРОВЕРИТЬ_СБОРКУ.bat`. Команда сверяет все файлы `build/` с контрольными суммами.
3. Запустите `ЗАГРУЗИТЬ_В_VK.bat`. Это обычная загрузка в **production и dev с обновлением рабочих URL игры**. При первом запуске введите числовой ID игры. Его можно поменять командой `npm run setup`. Требуется Node.js 18+; при отсутствии зависимостей BAT установит их через npm.
4. Пройдите авторизацию VK CLI в своём браузере. Не переносите токены или конфиги авторизации других игр. Основной скрипт задаёт `MINI_APPS_ENVIRONMENT=production`, `update_prod=true`, `update_dev=true`. Отдельный `ЗАГРУЗИТЬ_ТОЛЬКО_DEV.bat` задаёт dev и `update_prod=false`: рабочие URL при этом не меняются. Аналогичные команды: `npm run deploy` и `npm run deploy:dev`.
5. Откройте игру в VK на компьютере и телефоне. Проверьте реальную загрузку SDK, облачные сохранения, паузу при потере фокуса, звук, рекламу с наградой и возврат из неё. Локальные тесты SDK используют имитации и не заменяют этот проход в приложении VK. Для предварительной проверки отдельно доступна загрузка только в dev.
6. Перенесите информацию из `ТЕКСТЫ_ДЛЯ_КАРТОЧКИ_VK.md` (или `.txt`) в анкету. Заполните ID, автора, контакты и юридические ссылки. Уточните возрастную категорию по анкете.
7. Загрузите скриншоты из `media/screenshots/`, ролик из `media/video/` и оформление из `media/branding/`. Предлагаемый порядок скриншотов — по номерам. Актуальные требования к дополнительным полям и оформлению смотрите непосредственно в форме VK.
8. После проверки отправьте приложение на модерацию через кабинет. Основной BAT уже обновляет production URL при успешной загрузке; отправка на модерацию и публикация в каталоге остаются отдельными действиями владельца. Подготовка комплекта не выполняла ни загрузку, ни публикацию.

## Что находится в папке

- `build/` — многофайловая сборка VK/ОК; только она отправляется на хостинг. Внешний Yandex SDK ей не нужен.
- `build.zip` — архив той же сборки для ручной передачи или другого хостинга. CLI загружает `build/`.
- `preview.html` — автономная версия для локального просмотра. Не помещайте её вместо `build/index.html` на VK Hosting.
- `media/` — материалы карточки, не часть загружаемой игры.
- `archives/` — сохранённые архивы текущего релиза и исходников.
- `release-manifest.json` — SHA-256 файлов сборки; `kit-manifest.json` — состав всего комплекта без node_modules.
- `ПРОВЕРКИ.md` — выполненные проверки и граница локальной проверки.

`vk-hosting-config.json` содержит `app_id: 0` до ввода ID владельцем. Настройки `static_path: build` и пути `index.html` для mobile/web/mvk менять не нужно. Проверка остановит запуск без ID. Известный ID «Неонового Роя» заблокирован как чужой для этой игры.

## Уже выполненные проверки

Проверены игровые сценарии и 12 групп релизных проверок, включая имитации VK/ОК, паузу и прерывание рекламы. Проверены личные рекорды, календарь и статистика, косметика и 24 этапа комнаты в шести размерах экрана. Проверка коллекции `npm run verify -- --allow-edits` завершилась без ошибок. Подробности — в документах проекта и сохранённых отчётах `test-results/`.

При подготовке комплекта отдельно проверяются разрешения PNG, длительность и декодирование MP4, наличие звука, отсутствие ошибок JavaScript при съёмке, совпадение preview и SHA-256 файлов. Подтверждённая публикация в VK отсутствует; реальные платежи VK не подключены; общей таблицы игроков нет.
