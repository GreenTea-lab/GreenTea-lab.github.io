## Платформенная интеграция

- Отдельный официальный VK Bridge 2.15.5, встроенный в `dist-vk/game.js`.
  Яндекс SDK в VK-сборке не загружается. Вся игра и шрифты локальные.
- Проверяется результат CheckNativeAds. Рекламные кнопки скрыты при
  false/error/timeout; перед показом выполняется повторная проверка.
  В ОК ролики предлагаются только Android-клиенту по таблице совместимости.
- Нет фиктивной рекламной награды в автономном запуске. Только result === true
  выдаёт награду. Повторный запрос блокируется; отмена и ошибка награды не дают.
  Короткого тайм-аута у открытого ролика нет, ввод и звук остановлены до ответа.
- Межэкранная реклама на переходах, интервал 150 секунд. Первые три уровня
  кампании проходят без неё. Купленное ранее «Без рекламы» учитывается.
- При blur, скрытии страницы и ViewHide перетаскивание отменяется,
  игра остаётся на паузе после возвращения. Гонка отложенного WebAudio.resume
  закрыта повторной проверкой причин остановки.
- Локальное и облачное сохранение; облако частями по 2000 символов,
  последовательная запись, два поколения и переключение указателя в конце.
  При ошибке указателя старая версия остаётся читаемой; следующая запись повторяет попытку.
- Продолжение сохраняет поле, фигуры, цели, счёт, ходы и состояние генератора.
  Есть совместимость с прежними сохранениями и отклонение повреждённого поля.
- Учитываются безопасные области экрана и события insets VK.
- Денежных покупок за голоса VK/ОКи и общего рейтинга нет; записи личные.
  Монеты доступны за игру, подарок и задачу дня. Яндекс-покупки сохранены
  только в Яндекс-адаптере.
- Лицензии шрифтов и VK Bridge включены в HTML и THIRD_PARTY_NOTICES.txt.

## Проверки

`npm run test:release`: семь конфигураций (VK desktop, Android, iOS,
Mob.Web landscape EN; ОК Web, Android, iOS 320×568), пауза и реальные
события касаний Chrome, drag и tap-place, первый выигрыш, восстановление
уровня, облако при обрыве записи, длительный ролик, отмена и повторный запрос,
false/error/timeout рекламы, задача дня без повторной награды, восемь сцен,
процедурный резерв и автономный HTML без сетевых запросов.
Результат: 12 групп прошли, pageerror отсутствуют.
[Отчёт](test-results/moderation/report.json).

`npm run test:balance`: 334 кампанийных прогона, 330 побед.
Каждый из 140 уровней имеет хотя бы одну победу в проверенных сидах;
четыре проигрыша — в уровнях 13, 96, 115, 138, по одному из двух прогонов.
Старт: 60 из 60 побед у бота с 20% случайных ходов, медианы 2/2/1 ход.
30 задач дня начиная с 15.11.2026: 30 побед. Это оценка ботом, а не
данные живых игроков и не доказательство успеха при любой последовательности ходов.
[Отчёт](test-results/balance/report.json).

`npm run test:art`: три размера, десять декодированных изображений,
встроенные ресурсы, стабильный фон при reduced motion, сохранение отключения
анимации. Итоговые снимки — `test-results/art/`.

Контракты сверены с [официальным VK Bridge](https://github.com/VKCOM/vk-bridge)
и [таблицей совместимости ОК](https://apiok.ru/apps/vk).
Полная проверка всех пунктов актуальной редакции
[правил VK](https://dev.vk.ru/ru/mini-apps-rules) не заявляется.

Общая `npm run verify -- --allow-edits` также прошла: 2730 файлов материалов
неизменны, синтаксис 524 модулей и 28 HTTP-страниц проверен без ошибок.
Это проверка всей коллекции, отдельно от игрового теста этой игры.

## Перед отправкой

Проверить реальный HTTPS-адрес в заявленных клиентах VK/ОК на физических
iOS/Android: загрузку, скорость, настоящую рекламу, облако, сворачивание и возврат.
В автоматических проверках ответы Bridge эмулировались родительским iframe.
Сверить актуальные правила и карточку приложения: название, возраст,
иконку, описание, контакты и новые скриншоты. Старая реклама из архивов
может не соответствовать текущей версии.
