# Версия 2.4 · 15.11.2026

## Календарь побед

Путь: **Задача дня → Календарь побед**. Звёздочка отмечает дату задачи,
которую игрок завершил. Можно смотреть месяцы с сохранённой историей;
будущие дни не предлагают игру. Кнопка снизу запускает сегодняшнюю задачу.
Пропуски ничего не сбрасывают. Неделя начинается с понедельника.

Старое сохранение содержит только последнюю дату ежедневной победы и
общее количество. Переносится именно эта известная дата. Остальные
прошлые дни не восстанавливаются предположениями; счётчик огоньков и
прежние награды сохранены. Новые победы хранятся по датам.

Исправлена возможность повторной награды при переходе между старой
незавершённой задачей и новой датой: история проверяет каждую дату,
а не только последнее значение `challenge.claimed`. Уже пройденная задача
не выдаёт монеты второй раз. Победа после полуночи отмечает дату самой
задачи; действия и результат партии попадают в статистику дня завершения.

## Личная статистика

Пути: **Задача дня → Статистика** или **Настройки → Статистика**.
Вкладки «За день» и «За месяц», стрелки для просмотра прошлых периодов.
По местному времени устройства учитываются:

- рекорд завершённых партий классики;
- победы в головоломках, включая повторные прохождения;
- даты с победой в задаче дня, без повторного счёта одной даты;
- завершённые партии классики;
- собранные линии, предметы и сделанные ходы во всех режимах.

Месячный рекорд — максимум рекордов дней, остальные счётчики суммируются.
Отмена хода не вычитает уже выполненные действия; сбор предметов молотком
и при продолжении также учитывается. Двойное завершение одной партии
не увеличивает статистику повторно. Незавершённая классика не считается
новым рекордом периода. Прежний общий рекорд показан отдельно.

Учёт подробных действий начинается с обновления; дата начала видна
в окне. Старый общий рекорд не переносится в сегодняшний или месячный.
История сохраняется локально и вместе с остальным прогрессом в облаке.
Дни хранятся компактными массивами семи счётчиков; повреждённые записи
отбрасываются/нормализуются при чтении.

## Комната после 112 звёзд

Первые 13 наград и их пороги сохранены. Дальше открываются 13 улучшений
существующих мест: предмет становится богаче, а комната не заполняется
мелкими дубликатами. Все улучшения остаются частью главного фона;
отдельной коллекции или покупки за монеты нет. Следующая цель показана
в путешествии. Если звёзды уже были заработаны, улучшения доступны сразу.

| Звёзды | Улучшение |
|---:|---|
| 180 | Фарфоровая чайная пара |
| 280 | Домашняя библиотека |
| 400 | Вязаный шарф |
| 550 | Ягодный торт |
| 720 | Латунный канделябр |
| 920 | Букет роз |
| 1150 | Каминные часы |
| 1420 | Лежанка для кота |
| 1750 | Корзинка варенья |
| 2100 | Самовар |
| 2500 | Письменный набор |
| 2800 | Музыкальная шкатулка |
| 3000 | Набор для чтения |

Итого 26 изображений декора для 13 мест. Пороги доходят до трёх звёзд
на каждом из 1000 уровней. Новые пропорции проверяются на тех же местах
мебели; на телефоне и в низком горизонтальном окне используется своя
расстановка. Облик брусков и поля от декора не зависит.

Изображения подготовлены встроенным image_gen: новая прозрачная иллюстрация
по референсу существующих предметов. Мастер:
`art/v2-4/generated/room-upgrades.png`,
[промпт](art/v2-4/prompts.json),
[пороги и подготовленные файлы](art/v2-4/manifest.json).
`node tools/prepare-room-upgrades.mjs` разрезает атлас и сохраняет WebP .93
в `static/decor/`, без перерисовки содержимого.

## Проверки

- `node test/retention.mjs`: даты и високосный год, сумма и максимум
  месяца; настоящие победы и повтор без награды; полночь и граница месяца;
  восстановление истории, старый общий рекорд и отсутствие выдуманных
  дат; пять размеров RU/EN; каждое из 13 улучшений и отсутствие
  пересечений с кнопками. Снимки: `test-results/retention/`.
- `node test/release.mjs`: прежние 12 групп VK/ОК, пауза, ползунки,
  реклама, касания, прерванная запись облака, первый уровень и автономность.
- `node test/robustness.mjs`, `node test/calendar.mjs`, `node test/room.mjs`,
  `node test/art.mjs`, `node test/refinement.mjs`: сохранения, старые
  режимы, расположение предметов, изображения, RU/EN и загрузка.
- `npm run verify -- --allow-edits`: целостность коллекции и ссылки.

Также исправлен выбор языка в автономной VK-сборке: до раннего выхода
из SDK учитывается язык браузера или `vk_language`. Новые окна проверены
с настоящими русскими и английскими строками.

Перечисленные браузерные проверки прошли. Смена даты, награды,
перезагрузка и 140 состояний комнаты (14 порогов × пять размеров × два
языка) проверены в новом тесте. Основной платформенный прогон — 12 групп.

Общий `npm run verify -- --allow-edits` завершился одной ошибкой вне этой
игры: `Generated preview does not preserve neon-swarm/game.js`.
У «Неонового Роя» сборка от 15.11 новее превью от 14.11; его файлы в рамках
этой задачи не менялись. Для «Блоков у камина» ошибок в общем отчёте нет;
отдельно проверено совпадение превью и актуальной сборки 2.4.

Файлы версии 2.4 находятся в `deliverables/` с `v2-4` в имени.
Прежние результаты сохранены. Это локальная сборка; на VK не загружалась.
