## Комплект загрузки VK · 15.11.2026

Подготовлен `deliverables/vk-upload-2.5.0/`: текущая сборка, проверка SHA-256,
VK deploy CLI, 8 настоящих скриншотов 1200×600, видео 1920×1080 на 28,52 с
со звуком игры, иконки и обложка, тексты карточки RU/EN и инструкция.
Просмотр медиа: `МАТЕРИАЛЫ.html` внутри комплекта. Скрипты подготовки:
`tools/capture-vk-media.mjs`, `tools/prepare-vk-upload.mjs`,
`tools/finalize-vk-upload.mjs`. App ID оставлен 0; запуск без ID блокируется.
Контакты и юридические ссылки заполняет владелец. Папка подготовлена
локально; загрузка на хостинг, проверка реальных SDK в VK и публикация —
отдельные действия. Код игры и версия 2.5.0 при подготовке медиа не менялись.
Основной `ЗАГРУЗИТЬ_В_VK.bat` / `npm run deploy` настроен на production + dev
с обновлением рабочих URL; отдельный `ЗАГРУЗИТЬ_ТОЛЬКО_DEV.bat` сохраняет
production URL. Режимы и ошибки запуска проверяются `node test/vk-upload.mjs`
без сетевой загрузки.

## Локальная версия 1.1.0 · 15.11.2026

Подготовлена отдельная сборка VK/ОК. Учтены замечания модерации
«Неонового Роя»: отсутствие публикаций и избранного, сохранение паузы
после настройки звука, короткое понятное начало. Публикация не выполнялась.

Сохранены исходные деревянные панели, объёмные кнопки, шрифты и бруски.
Добавлены 10 сгенерированных фонов (комната в двух ориентациях и 8 глав),
лёгкие фоновые эффекты с отключением, продолжение уровня, задача дня
и коллекция семи огоньков. Кампания: 140 уровней; первые три — учебные.

`npm run build` создаёт `dist/`, `dist-single/`, `dist-vk/`, `dist-vk-single/`.
`npm run test:release` проверяет браузерные сценарии с эмуляцией Bridge;
`npm run test:balance` — баланс и точное восстановление генератора;
`npm run test:art` — изображения, автономный запуск и reduced motion.
Обновление превью и ZIP: `./tools/package-release.ps1`.

Подробности: [MODERATION.md](MODERATION.md), [GENERATED_ART.md](GENERATED_ART.md),
[RELEASE.md](RELEASE.md). Сведения ниже описывают первоначальный импорт.

- Рабочий код: `src`.
- Дата последнего файла исходного кода: 2026-10-10.
- Превью: `preview/index.html` (2026-10-12).
- Источник: `games-part2.zip!/fireside-blocks/fireside-blocks-source.zip`.
- Последний найденный автономный HTML. Дата упаковки превью не означает новую версию игровой логики.

Зависимости: `npm ci` из этой папки. Сборка: `node build.mjs`. Результаты — `dist/` и `dist-single/`; у Neon Swarm также `dist-vk/`.

Материалы и ранние варианты находятся в `../../materials/`. Документы из архивов — справочные материалы; их команды не выполнялись при импорте.
