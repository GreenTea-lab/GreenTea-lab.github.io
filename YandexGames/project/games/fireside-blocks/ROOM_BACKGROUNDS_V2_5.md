# Цельные фоны комнаты · 2.5 · 15.11.2026

Наложение отдельных спрайтов предметов на комнату заменено цельными
сгенерированными изображениями. В каждом варианте предметы уже нарисованы
в интерьере с его перспективой, светом, отражениями и контактными тенями.
Старая функция `paintRoomDecor` больше не импортируется игровым рендером.
Изображения предметов остаются только для карточек наград и сохранённых
материалов; они не накладываются на фон главного меню.

## Набор

**48 фонов: 24 этапа × две композиции**, широкая и вертикальная.
Стартовый вариант содержит три начальных предмета; далее каждый порог
звёзд выбирает следующую целую картинку. Первые награды добавляются,
поздние улучшения заменяют соответствующую вещь. Пороги сохранены:

`0, 3, 8, 14, 22, 32, 44, 58, 74, 92, 112, 180, 280, 400, 550,
720, 920, 1150, 1420, 1750, 2100, 2500, 2800, 3000`.

Звёзды, кампания, календарь, личная статистика и настройки не сбрасываются.
Меню остаётся по центру в два ряда по три кнопки; на разных высотах оно
расположено выше, чтобы передний план комнаты меньше закрывался интерфейсом.
Мерцание света и искры камина сохранены, отключение движения работает.

## Генерация и файлы

Использован встроенный **image_gen**, режим редактирования двух прежних
фонов комнаты. Для каждого этапа — отдельный запрос с полным составом
предметов, сохранением интерьера и свободной центральной области под меню.
Серия просмотрена на контактных листах и выборочно крупно в интерфейсе.

`src/room-background.js`. Старые отдельные раскладки предметов для выбора
изображения не используются.

## Загрузка

В папочной VK/ОК-сборке загружается нужная комната; все 48 картинок не
скачиваются при первом запуске. В памяти хранится не более трёх декодированных
комнатных изображений. Новый фон подготавливается при получении награды.
Пока он грузится, может оставаться предыдущий; при ошибке есть резервная
комната, и игра продолжает работать. При следующем обращении после паузы
неудачная загрузка может повториться.

Автономный HTML содержит весь набор и поэтому вырос примерно до 29,23 MiB.
Для VK/ОК предназначен папочный ZIP с отдельными файлами.
Релизная сборка требует все 48 изображений; упаковщик отклоняет неполный
набор. Флаги `--partial` у подготовки и `--allow-partial-room-art` у сборщика
использовались только для промежуточного визуального просмотра.

## Проверки

- `node test/room.mjs`: 24 этапа на шести размерах экрана, выбор ориентации,
  сохранение стадии после перезагрузки, видимость кнопок, ограничение кеша,
  отсутствие спрайтовой композиции и резерв при отсутствии ресурса.
- `node test/retention.mjs`: календарь, даты, повторные награды, статистика,
  поздние этапы комнаты на RU/EN.
- `node test/refinement.mjs`: подписи, поля окон, загрузка и reduced motion.
- `node test/personal-records.mjs`: только личные рекорды в обеих сборках.
- `node test/release.mjs`: 12 групп VK/ОК — пауза, громкость, реклама,
  касания, облако, начало игры и автономный запуск.
- `npm run verify -- --allow-edits`: целостность коллекции и ссылки.

Перечисленные браузерные проверки прошли. Проверены 144 состояния комнаты
(24 этапа × шесть размеров), 48 разных файлов корректной ориентации,
RU/EN и все 12 платформенных групп. На контактных листах просмотрена
полная последовательность, крупные снимки интерфейса сохранены рядом.

Новые файлы с `v2-5` в имени находятся в `deliverables/`.
Прежние версии сохранены. На VK ничего не загружалось.
