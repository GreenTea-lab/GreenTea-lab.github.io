# Версия 2.0 · 15.11.2026

## Фон и рисунки

Стартовая комната заново сгенерирована после просмотра игры: трёхчетвертная
перспектива, паркет с направляющими линиями, крупный передний план, дальние
книжные полки, тёплый огонь и холодный свет окна. Средние тона светлее,
появились объём, мягкие тени и разделение планов. Есть отдельный мобильный
вариант. Деревянная вывеска, кнопки и шрифты сохранены.

Встроенный image_gen создал два прозрачных атласа с 24 предметами.
Иконки вырезаны по ячейкам, прозрачные поля поджаты, сохранены в WebP
256×256. На блоке размер рисунка увеличен с 66% до 84% клетки.
Прозрачность проверена; процедурные предметы остаются резервом.

Добавлены шесть окружений: яблоневый сад, чайный сад, библиотека,
лаванда, мастерская, северное сияние. Всего 16 фоновых изображений:
14 окружений плюс два варианта комнаты; часть глав использует общее
окружение с другими предметами, задачами и узорами.

PNG-мастера фонов: `art/backgrounds/generated/`; прежняя плоская комната
сохранена в `art/v1-backgrounds/`. Атласы: `art/v2/generated/`.
Точные промпты: [art/v2/prompts.json](art/v2/prompts.json).
Рабочие WebP: `static/backgrounds/`, `static/items/`; в обеих папках есть manifest.
Все новые растровые изображения созданы встроенным image_gen.

## 1000 уровней

20 глав. Первые 140 номеров, границы первых восьми глав и сохранённые
звёзды сохраняются. Старый предел продолжения 140 заменён на COUNT=1000.
Первые три учебные задачи из версии 1.1 сохранены.

Новые главы: Яблоневый сад, Пекарня, Чайный сад, Оранжерея,
Библиотека, В горах, У реки, Лаванда, Мастерская, Фестиваль,
Северное сияние, Обсерватория. В них 860 новых уровней.

Пять видов целей: сбор предметов, очки, полные линии, серии удачных
сборов, доставка всех отмеченных предметов со стартового поля.
В доставке новые предметы не подбрасываются. В отдельных задачах
приходят только прямые фигуры или фигуры до четырёх клеток.
Все особые правила объясняются перед запуском.

Сложность идёт волнами по десять задач: чередуются типы целей,
узоры, повороты, плотность, предметы и наборы фигур. Нет ограничения времени.
Генератор процедурный; это не 1000 вручную нарисованных полей.

Калибровщик подбирает salt, три успешных сида и норму ходов для каждого
нового уровня. При старте игра выбирает один из этих трёх вариантов.
В дополнительных независимых прогонах используются другие сиды.
При подборе длинные варианты отбрасываются: каждый выбранный вариант
нового уровня завершается эталонным ботом не более чем за 45 ходов.
Это не ограничение ходов для игрока; партию можно продолжать дольше.
Это подтверждение проходимости ботом, а не гарантия победы при любых ходах.

## Косметика и возвращение

- 24 набора брусков: к прежним десяти добавлены витраж, чеканная медь,
  мрамор, изразцы, джинса, пэчворк, созвездия, перламутр, вышивка,
  розовое дерево, морозное стекло, бамбук, мозаика и соты.
- 8 оформлений поля и лотка: орех, берёза, фарфор, нефрит,
  розовый сад, полночь, мёд, ледник.
- 6 эффектов очистки: искры, листья, снежинки, ромашки, бабочки, лунная пыль.
- Косметика покупается за игровые монеты или выдаётся за прогресс.
  Выбор и покупки сохраняются; правила игры от оформления не зависят.
- Альбом: по три награды на каждую главу, всего 60 отметок.
  За 3 победы — 60 монет, за половину главы — 120, за всю главу —
  300 и один из новых скинов. Существующий прогресс тоже учитывается.
  Повторное получение одной отметки блокируется.
- Три ежедневных поручения: 8 линий / 10 предметов / 2 победы;
  отдельные награды 40 / 60 / 80 монет.
- Задача дня теперь выбирается из 860 новых уровней и использует
  один из проверенных сидов. Ежедневный подарок и семь огоньков сохранены.
- Поход недели: пять задач из разных новых глав, отдельное продолжение,
  по 50 монет за четыре этапа, 250 за финал, эффект бабочек и памятный
  трофей. Обновление в понедельник по местному календарю.
  Завершённый недельный трофей препятствует повторной выдаче.

Перезапуск задачи дня и похода сохраняет режим: награды кампании
за них не начисляются. Старый поход не записывает партию в новую неделю.

## Проверки

- `npm run test:expansion`: 2580 побед из 2580 прогонов новых уровней,
  860 различных комбинаций поля, цели и модификатора; интерфейс на
  1440×900, 390×844, 320×568; покупка/выбор/восстановление косметики,
  альбом без повторной награды, все типы целей, недельный финал,
  сохранение и победа на тысячном уровне.
- `npm run test:balance`: 2054 дополнительных прогонов кампании,
  2031 победа; 60 из 60 стартовых партий с 20% случайных ходов;
  30 из 30 задач дня. Эти дополнительные сиды не отбирались по успеху.
- `npm run test:release`: 12 групп прошли, семь конфигураций VK/ОК,
  сенсорное управление, пауза, реклама, отмена, тайм-аут проверки
  доступности, облако при обрыве записи, автономный запуск.
- `npm run test:art`: 16 фонов, 24 прозрачных спрайта, reduced motion,
  сохранение настройки анимации, три размера экрана.
- `node test/calendar.mjs`: перезапуск сохраняет принадлежность к режиму,
  истёкшая неделя не перезаписывает новую, трофей не выдаётся повторно.

Отчёты: `test-results/expansion/`, `test-results/balance/`,
