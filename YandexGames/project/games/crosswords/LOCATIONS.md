# 40 живописных локаций — версия 2.1.0

16.11.2026. Для кампаний созданы 40 новых самостоятельных иллюстраций встроенным ImageGen: 20 для обычных уровней и 20 для эрудитов. Вместо повторения 12 пейзажей через каждые 15 уровней каждый режим теперь разделён на 20 глав по 50 уровней. Между главами нет повторного использования одного фона; у эрудитов отдельный маршрут.

Изменена группировка глав и оформление. Сами 1000+1000 полей в каждом языке, ответы, номера уровней, звёзды и начатые партии сохранены. Проверка отсутствия повторов ответов остаётся частью сборки.

## Поведение

- У глав собственные иллюстрированные обложки; список сворачивается по главам, текущая открывается автоматически. Внутри — 50 уровней.
- Название текущей локации отображается под номером кроссворда.
- Между фонами плавный переход. При быстрой смене уровней запоздавшая загрузка не подменяет выбранную локацию.
- Поверх рисунков — деликатные лепестки, пыльца, снег или огоньки. Анимация выключается в настройках, при системном уменьшении движения и в скрытой вкладке.
- Ночная тема затемняет иллюстрацию; контрастная тема и выключенные локации дают спокойный однотонный фон.
- На хостинге полноразмерный рисунок загружается для текущей локации. Обложки используют отдельные маленькие файлы 640×240, с ленивой загрузкой. Автономное превью содержит все иллюстрации внутри HTML и поэтому больше многофайловой сборки.

## Файлы и воспроизведение

- `src/locations.js` — маршруты RU/EN и связь номера уровня с локацией.
- `src/location-scene.js` — показ иллюстраций, переходы и частицы.
- `static/locations/<id>.jpg` — 40 рисунков 1536×1024.
- `static/locations/<id>-thumb.jpg` — 40 обложек 640×240.
- `tools/location-art.json` — точный итоговый промпт для каждого изображения. Использован встроенный ImageGen, без CLI/API.
- `tools/location-art-sources.json` — соответствие результата генерации и имени файла проекта.
- `tools/prepare-location-art.ps1` — сжатие исходных PNG в JPEG и подготовка обложек. Исходники в каталоге ImageGen сохранены.

Для обычной сборки PNG из каталога ImageGen не нужны: готовые игровые JPEG включены в исходники. `npm run build` останавливается, если хотя бы один рисунок или обложка отсутствует. Флаг `--allow-partial-art` использовался только во время подготовки и не применяется к релизному архиву.

Проверки: `npm run test:locations` проверяет 40 разных файлов, 20+20 глав по 50 уровней, границы глав, названия, темы, быстрое переключение и пять размеров экрана. `npm run test:release` проверяет игровые сценарии и SDK. Отчёты находятся в `test-results/locations/` и `test-results/release/`.

Обе браузерные проверки пройдены, ошибок JavaScript нет. SHA-256 `ru.json` и `en.json` совпадают с файлами из сохранённого архива исходников 2.0.0; отчёт — `test-results/locations/content-preservation.json`. Общая `npm run verify -- --allow-edits` также завершилась без ошибок: проверены 2730 файлов материалов и все локальные страницы коллекции.
