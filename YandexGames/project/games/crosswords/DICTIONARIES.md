# Словари и отсутствие повторов

## Источники

1. Исходные `tools/words_<lang>_*.txt` из импортированного проекта: авторские вопросы и уровни обучения.
2. [Русский Викисловарь](https://ru.wiktionary.org/), авторы соответствующих статей, извлечение [Kaikki / Wiktextract](https://kaikki.org/ruwiktionary/) из дампа 01.11.2026. Скачан `https://kaikki.org/dictionary/downloads/ru/ru-extract.jsonl.gz`.
3. [WordNet 3.0](https://wordnet.princeton.edu/license-and-commercial-use), Princeton University: английские существительные и определения. Архив `https://wordnetcode.princeton.edu/3.0/WordNet-3.0.tar.gz`.
4. [FrequencyWords](https://github.com/hermitdave/FrequencyWords), Hermit Dave, OpenSubtitles 2018: полные частотные списки RU и EN, используемые для порядка сложности.

Тексты Викисловаря и частотные данные распространяются по [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Изменения: выбор самостоятельного значения, фильтрация помет и словоформ, удаление ударений, иногда выбор первой части определения; для игровых ответов Ё нормализована в Е. Примеры, цитаты авторов и произношения не импортируются. Адаптированные определения сохраняют CC BY-SA 4.0; это не меняет лицензию программного кода игры. Для авторства конкретного определения используется история исходной статьи; её имя сохранено четвёртым полем `ru-bank.json` и третьим полем `ru-used.json`.

WordNet сохраняет собственную разрешительную лицензию Princeton. MIT в репозитории FrequencyWords относится к его коду; данные имеют CC BY-SA 4.0. Полные уведомления о словарях, шрифтах и VK Bridge включены в сборку и доступны из настроек игры.

## Как получены уровни

`prepare-dictionary.mjs` извлекает и фильтрует слова; `expand-levels.mjs` добавляет исходные авторские вопросы и собирает **оба режима вместе**. Общий набор использованных ответов блокирует повтор слова в другом поле или другом режиме. Для определения повторов регистр и Ё/Е нормализуются. Разные вопросы к одному ответу не позволяют использовать его повторно.

Первый кроссворд сохранён, остальные поля пересобраны. Русская версия использует 17 036 разных ответов; английская — столько же. В каждом языке 8040 ответов обычной кампании и 8996 у эрудитов. Числа проверяются заново при каждой сборке, а не только записаны в интерфейсе.

Обычные поля содержат 5–9 слов, эрудиты 8–10. Наборы вопросов, координаты и сетки записаны заранее в `src/data/ru.json` и `en.json`; генерация кампании на устройстве игрока не требуется. Начатые партии прежней версии продолжаются из сохранённого снимка старого поля.

`src/data/<lang>.json:bank` — отдельные 3000 слов для задачи дня. Они не пересекаются с кампаниями; между разными датами ежедневного режима слова могут встречаться вновь. Бесконечное число ежедневных задач не может иметь бесконечный неповторяющийся запас в автономной игре.

## Воспроизведение

Из папки игры:

```
npm ci
npm run generate
npm run test:levels
node tools/validate-daily.mjs
npm run build
npm run test:release
```

Генератор использует сохранённые отфильтрованные `tools/dictionaries/ru-bank.json` и `en-bank.json`. Полный исходный дамп и частотные списки не требуются для обычной сборки. Для повторного извлечения скачайте приведённые исходники в `tools/dictionaries/`, распакуйте `dict/data.noun`, `dict/index.noun` и `LICENSE` WordNet и запустите `node tools/prepare-dictionary.mjs`. Полные списки частот: `https://raw.githubusercontent.com/hermitdave/FrequencyWords/master/content/2018/ru/ru_full.txt` и аналогичный путь `en/en_full.txt`; локальные имена `ru-frequency.txt` и `en-frequency.txt`.

Старые `genlevels.mjs` / `genadult.mjs` — сохранённые первоначальные генераторы на 180/30 уровней, они исключены из команды сборки. Для релиза 2.0 используйте `npm run generate`.
