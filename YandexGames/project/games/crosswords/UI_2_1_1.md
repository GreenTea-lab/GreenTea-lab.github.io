# Интерфейс 2.1.1 · 16.11.2026

- Экран загрузки: фон читального зала, бумажная карточка с золотой рамкой, объёмная эмблема кроссворда, лёгкая анимация букв. Индикатор проходит реальные этапы запуска: SDK, сохранения, покупки, шрифты и создание интерфейса. Задержка для демонстрации загрузки не добавлялась. Тексты RU/EN, анимация отключается при reduced motion.
- Список вопросов справа доступен при ширине от 900 px независимо от пропорций окна и в горизонтальных окнах от 700 px с отношением сторон больше 1,35. Убрано скрытие списка в низком горизонтальном режиме.
- В широкой раскладке клавиатура находится под сеткой, оставляя правой панели место для вопросов. На телефоне клавиатура и кнопка списка остаются в прежней раскладке. При изменении размера перемещается один существующий элемент клавиатуры: ввод и обработчики сохраняются.
- Словари, уровни, награды, идентификаторы сохранений и все 40 фонов сохранены.

`npm run test:layout`: семь размеров окна (1440×900, 1024×900, 900×1200, 1280×720, 844×390, 390×844, 320×568), размещение загрузочной карточки, правая панель, выбор слова нажатием на вопрос, клавиатурный ввод после повторных изменений размера. Результаты и снимки: `test-results/layout/`.

Проверки пройдены: `test:layout`, `test:locations`, `test:release` (10 сценариев, без ошибок JavaScript), строгая проверка всех полей при сборке и `npm run verify -- --allow-edits` для всей коллекции.

Сборки локальные, на VK не загружались. Архивы 2.1.0 сохранены.
