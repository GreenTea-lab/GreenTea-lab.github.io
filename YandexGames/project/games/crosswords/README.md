# Кроссворды. Классика 2.1.2

Спокойная игра с крупным текстом, экранной клавиатурой, тремя темами и сохранением незаконченной партии. Локальная подготовка для VK/ОК завершена 16.11.2026; публикация не выполнялась.

- 1000 обычных и 1000 уровней эрудитов в каждой языковой версии, RU и EN.
- 17 036 разных ответов в каждом языке: обычный режим и эрудиты не повторяют ответы друг друга.
- Задача дня с отдельным запасом слов, архив за 30 дней, цели недели и словарик с избранным.
- Подсказки буквы/слова за монеты, бесплатная проверка и очистка ошибок, карандаш, увеличение и прокрутка поля.
- 40 сгенерированных живописных локаций: по 20 глав на 50 уровней для каждого режима, без циклического повторения пейзажей. Обложки глав, частицы и отдельный читальный зал в меню.
- В VK/ОК: официальный VK Bridge, облачное хранение, поддерживаемая реклама, личные результаты. В поддерживаемом VK — редактор истории по нажатию. Денежные покупки VK и общий рейтинг не подключены.

## Сборка и проверка

Из этой папки:

```
npm ci
npm run build
npm run test:levels
npm run test:daily
npm run test:release
npm run test:locations
npm run test:layout
```

`dist-vk/` — многофайловая сборка VK/ОК; `dist-vk-single/index.html` — её автономное превью. `dist/` и `dist-single/` — Яндекс-сборка и автономное превью для полки. Сборка сама проверяет все поля и завершается ошибкой при повторе ответа.

`npm run generate` заново создаёт кампании из сохранённых расширенных словарей. Старые `genlevels.mjs` и `genadult.mjs` относятся к исходным 180/30 уровням и не используются в релизе 2.0.

Браузерные проверки используют установленный Chrome через Playwright. Ответы VK/ОК эмулируются; это не проверка серверов платформы. Снимки и отчёты записываются в `test-results/`.
