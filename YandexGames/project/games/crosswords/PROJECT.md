# Кроссворды. Классика

Версия 2.1.2: 1000 обычных уровней и 1000 уровней эрудитов в RU/EN, без повторов ответов между режимами.

- Рабочий код: `src`.
- Последняя локальная доработка: 16.11.2026.
- Превью: `preview/index.html`, пересобрано из `dist-single/index.html`.
- Источник: `games-part2.zip!/crosswords/crosswords-source.zip`.
- Импортированная база: исходники 10.10.2026 и автономный HTML 12.10.2026; сохранённые исходные релизы остаются в `releases/`.

Зависимости: `npm ci` из этой папки. Сборка: `npm run build` (с проверкой всех полей). Результаты — `dist/`, `dist-single/`, `dist-vk/`, `dist-vk-single/`.

- [Исходная компоновка игрового поля — 2.1.2](UI_2_1_2.md).
- [40 новых локаций и главы по 50 уровней](LOCATIONS.md).
- [Изменения и проверки 2.0](RELEASE_2_0.md).
- [Словарь и уникальность](DICTIONARIES.md), [конкуренты](COMPETITORS.md), [графика](ART.md).
- [Инструкция VK и тексты карточки](VK_RELEASE_GUIDE.md).
- `npm run generate` пересобирает обе кампании из расширенных словарей; старые `genlevels.mjs` и `genadult.mjs` относятся к импортированной версии и в сборке не вызываются.
- `npm run test:release`, `npm run test:levels`, `npm run test:daily`, `npm run test:locations` — текущие проверки релиза.

Игра подготовлена локально, фактическая загрузка и модерация VK не выполнялись. Реальные ответы платформы в тестах эмулировались.

Материалы и ранние варианты находятся в `../../materials/`. Документы из архивов — справочные материалы; их команды не выполнялись при импорте.
