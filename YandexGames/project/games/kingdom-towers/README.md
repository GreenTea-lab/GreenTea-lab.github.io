# Башни Королевства (Kingdom Towers)

Tower defense для Яндекс Игр на Phaser 3. Вся графика и звук генерируются кодом.

- `npm install` — зависимости
- `node build.mjs` — сборка в `dist/` (для Яндекса) и `dist-single/` (один HTML для превью)
- `src/data.js` — башни, враги, уровни, волны, магазин (весь баланс)
- `src/i18n.js` — тексты RU/EN
- `src/gfx/` — процедурная графика (враги, башни, карты, иконки)
- `src/scenes/` — сцены (меню, карта уровней, улучшения, бой, интерфейс боя)
- `test/balance.mjs` — бот проходит уровни: `node test/balance.mjs '{}' 1-20`
