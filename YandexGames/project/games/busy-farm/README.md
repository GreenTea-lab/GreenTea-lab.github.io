# Хлопотливая ферма (Busy Farm)

Three.js, процедурная графика и звук, без внешних ассетов.

- `npm install`, затем `node build.mjs` → `dist/` (для Яндекс Игр) и `dist-single/index.html` (один файл для превью).
- `src/sim.js` — симуляция фермы (работает в node), `src/data.js` — уровни, цены, баланс, `src/bot.js` — бот для калибровки.
- `node test/calib.mjs` — прогон всех уровней ботом против времени на золото.
- `test/*.mjs` — проверки в браузере (playwright), `promo/*.mjs` — иконка, обложки, скриншоты, видео, покупки.
