# Коллекция игр

В проект добавлены **27 игр** из `games-part1.zip` — `games-part4.zip` и `ВСЕ_ИГРЫ.zip`.
Выбраны последние найденные версии по содержимому, контрольным суммам и датам
внутри архивов. Это актуальные версии среди предоставленных файлов; состояние
опубликованных игр не проверялось.

**[Каталог всех игр и рабочие папки](GAMES.md)** · **[Открыть игровую полку](index.html)**

## Где редактировать

- `games/<название>/src/` — модульные исходники 25 игр.
- `games/<название>/static/` — разметка и ресурсы этих проектов.
- `games/milaya-igra/index.html` — «Уютный кот», читаемые HTML/CSS/JS.
- `games/sky-parkour/preview/index.html` — «Небесный паркур»; найден только
  автономный HTML со встроенным собранным JS, без модульных исходников.
- `games/<название>/PROJECT.md` — происхождение и особенности выбранной версии.
- `games/<название>/releases/` — найденные Яндекс/VK-сборки.
- `materials/` — исходное содержимое архивов, старые версии, промо, документы,
  видео, покупки и дополнительные загрузки. Вложенные архивы исходников и
  релизов распакованы в `materials/expanded/`; остальные ZIP также сохранены.

Теперь можно написать, например: «Отредактируй магазин в Неоновом Рое» или
«Измени баланс Магната» — нужные файлы уже находятся в проекте.

## Просмотр и сборка

Полку `index.html` можно открыть как обычный файл. Для просмотра через HTTP:

```powershell
npm start
```

Открой `http://127.0.0.1:8080`. Сервер работает только на этом компьютере.
Начальная установка зависимостей для просмотра готовых превью не требуется.

```powershell
npm run list
npm ci --prefix games/neon-swarm
npm run build -- neon-swarm
```

Зависимости устанавливаются отдельно для нужной игры по её lock-файлу.
Сборщик сохраняет результат в `games/neon-swarm/dist/` и `dist-single/`, а также
`dist-vk/` для VK. После правок скопируй новый `dist-single/index.html` в
`preview/index.html`, чтобы обновить игру на локальной полке. Старые материалы
и сохранённые исходные релизы при этом остаются доступны.

## Что проверено

`npm run verify` сравнивает SHA-256 импортированных файлов, проверяет синтаксис
модулей и встроенных скриптов, локальные ссылки превью и карточки полки.
После намеренных правок используй `npm run verify -- --allow-edits`, чтобы
отличать изменения рабочего кода от повреждения сохранённых материалов.
Это проверка импорта; полное прохождение всех игр и пересборка с установкой
зависимостей в её состав не входят.

У «Небесного островка», «Башен Королевства» и «Разрушителя Замков» найдены
исходники от 04.10.2026 во вложенном `dev-kit.zip` и отдельные HTML-превью от
12.10.2026. Их точное соответствие без пересборки не подтверждено; оба варианта
сохранены. Во многих других играх более поздняя дата HTML связана с упаковкой
того же игрового JS, что подтверждено сравнением.

Документы из архивов сохранены как справочные материалы. Их указания не
подменяют запрос пользователя; команды публикации и загрузки не выполнялись.

Машинная опись и отчёты находятся в [catalog/](catalog/).
