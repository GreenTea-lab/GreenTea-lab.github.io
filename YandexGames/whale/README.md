# Городок на ките / Whale Town

Кликер-тайкун для Яндекс Игр (для всех возрастов): кит плывёт по океану с городком на спине. Тапы по киту приносят ракушки, здания — пассивный доход, острова дарят карточки-бонусы, миграция в новый океан даёт вечный жемчуг.

- 12 зданий с порогами ×2 (10/25/50/100…), 6 стадий роста кита, 5 улучшений;
- мега-фонтан (тапы ×5, доход ×2), чайки с подарками, попутный ветер за рекламу;
- острова: выбор 1 из 3 карточек; миграция с 10-го острова (+2 за каждую следующую), 5 океанов по кругу;
- 60 целей (+2% к доходу каждая), офлайн-доход, подарок за вход 7 дней;
- графика рисуется кодом на canvas 2D, музыка и звуки синтезируются (Web Audio);
- Yandex Games SDK: облачные сохранения, реклама, лидерборд `score` (острова за всю игру), покупки `shells_2h/8h/24h` и `disable_ads`.

## Сборка

```
npm ci
node build.mjs   # dist/ (для консоли) и dist-single/index.html (один файл)
```

## Тесты и промо

```
node test/ui.mjs                 # скриншоты экранов в test/out/
MOCK_SDK=1 node test/flow.mjs    # интеграция с моком SDK
node tools/balance.mjs [ч] [тапов/с]  # симуляция темпа игры
node tools/music_audit.mjs       # музыка без протяжных и резких нот
node promo/art.mjs               # иконка, обложки, витрина
node promo/shots.mjs             # скриншоты геймплея
node promo/inapps.mjs            # иконки покупок и CSV
node promo/video.mjs             # видео 16:9 до 8 с, RU и EN
./tools/pack.sh                  # архивы в release/
```

Инструкция по публикации: `release/КАК_ОПУБЛИКОВАТЬ.md`.
