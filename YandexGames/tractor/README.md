# Ферма на тракторе / Tractor Farm

Спокойный 3D-симулятор фермы для Яндекс Игр без поражений: трактор сам выбирает орудие (плуг, сеялка, жатка), урожай растёт и при закрытой игре, продажа и заказы — в амбаре.

- 6 полей (клеточная маска 0,5 м: пашня, всходы, стерня), 5 культур, 4 трактора, 4 улучшения, заказы, уровни;
- low-poly модели собираются кодом (Three.js), смена дня и ночи, животные, частицы;
- управление: плавающий джойстик (палец или мышь) и WASD / стрелки;
- Yandex Games SDK: облачные сохранения, реклама, лидерборд `score`, покупки `coins_2000/8000/25000` и `disable_ads`;
- музыка и звуки, включая мотор, синтезируются (Web Audio).

## Сборка

```
npm ci
node build.mjs   # dist/ (для консоли) и dist-single/index.html (один файл)
```

## Тесты и промо

```
node test/ui.mjs                 # скриншоты экранов в test/out/
MOCK_SDK=1 node test/flow.mjs    # интеграция с моком SDK
node test/ads.mjs                # правила полноэкранной рекламы
node tools/music_audit.mjs       # музыка без протяжных и резких нот
node promo/art.mjs               # иконка, обложки, витрина
node promo/shots.mjs             # скриншоты геймплея
node promo/inapps.mjs            # иконки покупок и CSV
node promo/video.mjs             # видео 16:9 до 8 с, RU и EN (долго: рендер программный)
./tools/pack.sh                  # архивы в release/
```

Инструкция по публикации: `release/КАК_ОПУБЛИКОВАТЬ.md`.
