# Кроссворды. Классика / Classic Crosswords

Классические кроссворды для Яндекс Игр, рассчитаны на взрослую аудиторию (40+): крупные клетки и шрифт, три размера текста, светлая, контрастная и ночная темы, экранная клавиатура.

- 120 кроссвордов на русском и 120 на английском (8 глав по 15), кроссворд дня;
- подсказки «Буква» и «Слово» за монеты, бесплатная «Проверка»;
- Yandex Games SDK: облачные сохранения, реклама (полноэкранная и за награду), лидерборд `score`, покупки `coins_300/1000/3000` и `disable_ads`;
- процедурная музыка и звуки (Web Audio), без внешних ресурсов.

## Сборка

```
npm ci
node tools/genlevels.mjs   # словари tools/words_*.txt -> src/data/*.json (уровни и банк слов)
node tools/validate.mjs    # проверка сеток: нет лишних слов и конфликтов
node build.mjs             # dist/ (для консоли) и dist-single/index.html (один файл для превью)
```

## Тесты

```
node test/ui.mjs                 # скриншоты экранов в test/out/
MOCK_SDK=1 node test/flow.mjs    # интеграция с моком SDK: реклама, покупки, сохранения, кроссворд дня
node tools/music_audit.mjs       # музыка без протяжных и резких нот
```

## Промо

```
node promo/art.mjs       # иконка, обложки, витрина
```
