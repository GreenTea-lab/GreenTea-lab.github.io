# Клёвая рыбалка / Cozy Fishing

Спокойная рыбалка для Яндекс Игр (аудитория 40+): заброс касанием воды, поклёвка, подсечка, вываживание «держи — отпускай», атлас из 29 видов рыб на пяти водоёмах.

- время суток в игре — по часам игрока (ночью клюют сом, судак, налим), погода меняется 4 раза в сутки;
- ежедневное: подарок за вход (7 дней по кругу), три задания дня и сундук, рыба дня ×2, коптильня работает при закрытой игре;
- кот Мурзик приходит в гости и за рыбку приносит удачу, золотая рыбка исполняет желание;
- снасти (удочка, катушка, леска, садок, коптильня), наживка (червь, опарыш, кукуруза, блесна, золотая мормышка);
- графика рисуется кодом на canvas 2D, музыка и звуки синтезируются (Web Audio);
- Yandex Games SDK: облачные сохранения, реклама, лидерборд `score` (общий улов в граммах), покупки `coins_1000/5000/15000` и `disable_ads`.

## Сборка

```
npm ci
node build.mjs   # dist/ (для консоли) и dist-single/index.html (один файл)
```

## Тесты и промо

```
node test/ui.mjs                 # скриншоты экранов в test/out/
MOCK_SDK=1 node test/flow.mjs    # интеграция с моком SDK
node test/daily.mjs              # подарки, задания, погода, вероятности улова
node tools/balance.mjs           # баланс вываживания и доход в минуту
node tools/music_audit.mjs       # музыка без протяжных и резких нот
node promo/art.mjs               # иконка, обложки, витрина
node promo/shots.mjs             # скриншоты геймплея
node promo/inapps.mjs            # иконки покупок и CSV
node promo/video.mjs             # видео 16:9 до 8 с, RU и EN
./tools/pack.sh                  # архивы в release/
```

Инструкция по публикации: `release/КАК_ОПУБЛИКОВАТЬ.md`.
