# Судоку. Дзен-сад / Zen Garden Sudoku

Судоку для Яндекс Игр в стилистике японского сада, для аудитории 40+: крупные цифры, три размера текста, темы «Ночь», «Рассвет» и «Контраст».

- 120 судоку в четырёх садах (лёгкие, средние, сложные, эксперт), бесконечная свободная игра, судоку дня;
- все головоломки с единственным решением и решаются логикой (оценка по приёмам: одиночки, пересечения, пары, тройки, «крестокрыл»);
- «Мой сад»: 16 предметов открываются за решённые судоку;
- заметки, отмена, подсказки, подсветка, таймер и рекорды;
- Yandex Games SDK: облачные сохранения, реклама, лидерборд `score`, покупки `coins_300/1000/3000` и `disable_ads`;
- процедурная графика (canvas, SVG), музыка и звуки (Web Audio), без внешних ресурсов.

## Сборка

```
npm ci
node tools/genpuzzles.mjs   # пулы головоломок -> src/data/puzzles.json (около 3 минут)
node build.mjs              # dist/ (для консоли) и dist-single/index.html (один файл)
```

## Тесты и промо

```
node test/ui.mjs                 # скриншоты экранов в test/out/
MOCK_SDK=1 node test/flow.mjs    # интеграция с моком SDK
node tools/music_audit.mjs       # музыка без протяжных и резких нот
node promo/art.mjs               # иконка, обложки, витрина
node promo/shots.mjs             # скриншоты геймплея
node promo/inapps.mjs            # иконки покупок и CSV
node promo/video.mjs             # видео 16:9 до 8 с, RU и EN
./tools/pack.sh                  # архивы в release/
```
