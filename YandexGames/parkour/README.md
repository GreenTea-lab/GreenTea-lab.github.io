# Небесный паркур / Sky Parkour 3D

3D-паркур от третьего лица для Яндекс Игр (обби): 40 уровней из парящих островов в 8 мирах — Луг, Конфетная страна, Пустыня, Ледник (скользкий лёд), Джунгли, Вулкан (лава), Неоновый город и Космос (низкая гравитация).

- препятствия: прыжки, балки, лестницы, зигзаги, повороты, батуты, движущиеся платформы и лифты, исчезающие плиты, вращающиеся диски, столбики, косилки;
- чекпоинты, монеты, звёзды за время (3 звезды — быстрее «эталона»), рекорды уровней;
- 10 скинов (8 за монеты, 2 за рекламу), подарок дня с серией до 7 дней;
- управление: WASD/стрелки + пробел + мышь (Q/E), на телефоне — джойстик слева, кнопка прыжка и свайп камеры справа;
- Three.js: InstancedMesh, тени за игроком, авто-качество; физика с фиксированным шагом 1/120 с;
- уровни строятся генератором из сегментов, проходимость проверяется статически (`tools/levels.mjs`) и ботом на настоящей физике (`tools/bot.mjs`);
- Yandex Games SDK: облачные сохранения, реклама, лидерборд `score` (все звёзды), покупки `coins_500/2000/6000` и `disable_ads`.

## Сборка

```
npm ci
node build.mjs   # dist/ (для консоли) и dist-single/index.html (один файл)
```

## Тесты и промо

```
node tools/levels.mjs            # статическая проверка всех 40 уровней
node tools/bot.mjs [уровень]     # бот проходит уровни на физике
node tools/music_audit.mjs       # музыка без протяжных и резких нот
node test/ui.mjs [d|m]           # скриншоты экранов в test/out/
node test/flow.mjs               # интеграция с моком SDK
node test/jump.mjs               # прыжок при 60–240 Гц, короткие тапы, фокус кнопок
node promo/art.mjs && sh promo/fit.sh   # иконка, обложки, витрина
node promo/shots.mjs             # скриншоты геймплея
node promo/inapps.mjs            # иконки покупок и CSV
node promo/video.mjs             # видео 16:9 до 8 с, RU и EN (геймплей ведёт бот)
./tools/pack.sh                  # архивы в release/
```

Инструкция по публикации: `release/КАК_ОПУБЛИКОВАТЬ.md`.
